# CZ 통제실 v1.1

**CHZZK 방송 통합관제 시스템**

CHZZK의 여러 방송을 한 화면에서 동시에 시청하고 관리할 수 있는 Manifest V3 확장 프로그램입니다.

## 주요 기능

- 방송 URL 또는 UID로 방송 추가
- 기본 레이아웃: 2×2 / 3×3 자동 전환
- 메인/서브 레이아웃
- 방송 목록 관리 및 개별/전체 삭제
- 즐겨찾기
- 방송별 음소거
- 화면 잠금: 플레이어 조작 방지
- 채팅 패널 표시 및 닫기/열기
- 드래그 앤 드롭으로 방송 순서 변경
- 방송 타일의 CHZZK 넓은 화면 모드 자동 적용
- 모니터 해상도 및 창 크기에 따른 타일 자동 조정
- 화면에 표시되지 않는 방송은 iframe을 생성하지 않아 불필요한 재생/음성 방지

## 표시 개수

- **기본 레이아웃:** 최대 9개 방송
- **메인/서브 레이아웃:** 최대 4개 방송
- 표시 제한을 초과한 방송도 목록에서는 삭제되지 않으며, 레이아웃을 변경하면 다시 표시할 수 있습니다.

## 설치

1. ZIP 파일을 압축 해제합니다.
2. Chrome / Edge / Whale에서 확장 프로그램 관리 페이지를 엽니다.
3. **개발자 모드**를 활성화합니다.
4. **압축해제된 확장 프로그램을 로드**를 선택합니다.
5. 압축 해제한 `CZ 통제실` 폴더를 선택합니다.

## 사용 방법

1. 확장 프로그램 팝업에서 방송 URL 또는 UID를 입력해 목록에 추가합니다.
2. 필요한 경우 저장된 방송 목록이나 즐겨찾기를 이용합니다.
3. **멀티뷰 열기**를 선택하면 별도의 새 탭에서 통제실이 실행됩니다.
4. 레이아웃과 채팅 표시 여부를 원하는 형태로 조정합니다.
