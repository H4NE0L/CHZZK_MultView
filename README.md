# CZ 통제실 v1.1.7

**CHZZK 방송 통합관제 시스템**

CHZZK의 여러 방송을 한 화면에서 동시에 시청하고 관리할 수 있도록 만든 Chrome / Edge / Whale용 Manifest V3 확장 프로그램입니다.

---

## 주요 기능

### 방송 관리

* CHZZK 방송 URL 또는 UID로 방송 추가
* 다시보기 영상 URL 지원

  * `https://chzzk.naver.com/video/{영상ID}`
  * `video/{영상ID}`
* 현재 방송 목록 확인
* 개별 방송 삭제 / 전체 방송 삭제
* 방송 타일 드래그 앤 드롭으로 순서 변경
* 방송 타일의 `메인으로 변경` 버튼으로 메인 방송 지정
* 방송 타일의 `링크 생성` 버튼으로 CHZZK 방송 링크 복사
* 즐겨찾기 등록 및 해제
* 즐겨찾기 그룹 추가 / 이름 변경 / 삭제
* 즐겨찾기 그룹 순서 변경
* 즐겨찾기 방송의 그룹 변경
* 즐겨찾기 방송 전체 순서 변경
* 즐겨찾기 방송 온라인 / 오프라인 상태 확인
* 로그인된 CHZZK 환경에서 방송 재생 지원

### 멀티뷰 레이아웃

#### 기본 레이아웃

방송 수에 따라 화면을 자동으로 구성합니다.

* 1개: 1×1
* 2개: 2×1
* 3~4개: 2×2
* 5~6개: 3×2
* 7~9개: 3×3
* 최대 9개 방송을 화면에 표시

화면에 표시되지 않는 방송도 방송 목록에서는 삭제되지 않습니다.

#### 레이드 뷰

메인 방송 1개와 서브 방송 최대 3개를 함께 표시합니다.

* 최대 4개 방송 표시
* 메인 방송은 가장 큰 화면에 표시
* 메인 방송 변경 시 해당 방송이 자동으로 메인 위치로 이동
* 채팅창 위치에 따라 `1+3` / `3+1` 배치 자동 전환
* 채팅 왼쪽: 메인 화면 왼쪽 / 서브 화면 오른쪽
* 채팅 오른쪽: 서브 화면 왼쪽 / 메인 화면 오른쪽

## 즐겨찾기

팝업과 멀티뷰에서 동일한 즐겨찾기 데이터를 사용하며, 그룹과 방송 순서를 함께 관리할 수 있습니다.

### 즐겨찾기 그룹 관리

* `기본 그룹` 제공
* 사용자 그룹 추가
* 그룹명 변경
* 그룹 삭제
* `기본 그룹` 삭제 방지
* 그룹 삭제 시 해당 방송을 `기본 그룹`으로 이동
* 그룹 순서 변경
* 그룹 접기 / 펼치기
* 전체 그룹 또는 특정 그룹 보기

### 즐겨찾기 방송 관리

* 즐겨찾기 방송을 원하는 그룹으로 이동
* 전체 즐겨찾기 방송 순서 변경
* 즐겨찾기 개별 삭제
* 브라우저/PC 재시작 후에도 그룹 및 방송 순서 유지
* 기존 즐겨찾기 데이터 자동 마이그레이션 지원

즐겨찾기 조회 목록과 관리 화면의 역할을 분리하여, 조회 화면에서는 방송을 빠르게 확인하고 관리 화면에서는 그룹과 순서를 관리할 수 있도록 구성되어 있습니다.

### 온라인 상태

즐겨찾기 방송의 현재 온라인 상태를 확인할 수 있습니다.

* 온라인 / 오프라인 상태 확인
* 온라인 방송을 목록 상단에 우선 표시
* 그룹별 온라인 방송 수 표시
* 특정 그룹의 온라인 방송을 한 번에 멀티뷰에 추가
* `새로고침`을 통한 온라인 상태 수동 갱신
* 팝업과 멀티뷰에서 동일한 온라인 상태 데이터 사용

온라인 방송은 조회 목록에서 다음과 같이 표시됩니다.

* 초록색 상태 점
* `ONLINE` 배지
* 연한 초록색 배경

오프라인 방송은 `OFFLINE` 상태로 표시됩니다.

온라인 방송은 이름 아래에 **현재 방송 카테고리와 방송 시간**(예: `리그 오브 레전드 · 2시간 15분`)도 함께 표시됩니다.

## 싱크 조정

멀티뷰 상단 바의 `싱크` 버튼(볼륨 버튼 왼쪽)에서 방송별 싱크를 수동으로 맞출 수 있습니다.

* `-0.5`, `-0.1` : 방송을 뒤로 당김 (되감기, 지연 증가)
* `+0.1`, `+0.5` : 방송을 앞으로 밀어 라이브에 더 가깝게 이동
* 방송별 `초기화`, 상단의 `전체 초기화`
* 방송별 현재 싱크 조정값과 지연값 표시
* 패널 상단에서 조정된 방송과 조정 초 확인, 싱크 버튼에 조정된 방송 수 배지 표시

조정값은 저장되지 않으며 방송이 다시 로드되면 0초로 돌아갑니다. 다시보기 영상은 지원하지 않습니다.

## 음량 및 음소거

### 전체 볼륨

확장 프로그램 자체의 전체 볼륨을 조절합니다.

실제 재생 음량은 다음과 같이 적용됩니다.

`방송별 볼륨 × 전체 볼륨`

전체 볼륨을 변경해도 각 방송의 개별 볼륨 설정은 변경되지 않습니다.

### 방송별 볼륨

* 방송별 개별 볼륨 조절
* 방송별 음소거
* 음소거 해제 시 이전 볼륨으로 복귀
* 플레이어에서 직접 변경한 음량/음소거 상태도 통제실 UI에 동기화

### 메인만 듣기

`메인만 듣기`를 활성화하면 메인 방송의 소리만 들을 수 있습니다.

기존 방송별 음소거 설정은 별도로 유지됩니다.

## 채팅

* 각 방송에 대응하는 채팅 패널 제공
* 채팅창 열기 / 닫기
* 채팅창 좌 / 우 위치 변경
* 레이드 뷰에서 채팅 위치에 맞춰 메인/서브 영상 배치도 자동 변경
* 다시보기의 경우 CHZZK에서 제공하는 **라이브 채팅 다시보기**를 채팅 패널에서 불러옴

* 방송 타일은 CHZZK 플레이어의 넓은 화면 모드를 자동 적용
* 모니터 해상도와 브라우저 창 크기에 맞춰 타일 크기 자동 조정

* 화면 잠금 기능

  * 통제실의 방송 관리 기능은 계속 사용할 수 있음
* 방송 타일 상단 컨트롤은 평소 숨겨지고 타일에 마우스를 올리면 표시

## 팝업

확장 프로그램 팝업에서는 다음 기능을 제공합니다.

* 현재 확장 프로그램 버전 표시
* 방송 URL / UID 입력
* 저장된 방송 목록 관리
* 즐겨찾기 조회
* 즐겨찾기 그룹 관리
* 즐겨찾기 항목 관리
* 즐겨찾기 온라인 상태 확인
* 온라인 상태 새로고침
* 멀티뷰 열기

팝업 즐겨찾기 조회 영역은 방송을 빠르게 확인하고 멀티뷰에 추가하기 위한 용도로 사용하며, 그룹과 항목의 세부 관리는 각각 관리 화면에서 수행합니다.

팝업에서 특정 멀티뷰 목록을 선택하지 않고 멀티뷰를 열면 이전에 사용하던 멀티뷰 방송 목록을 복원할 수 있습니다.

## 멀티뷰 즐겨찾기

멀티뷰 상단의 즐겨찾기 메뉴에서도 팝업과 동일한 즐겨찾기 데이터를 확인할 수 있습니다.

* 그룹별 즐겨찾기 방송 확인
* 그룹 접기 / 펼치기
* 온라인 방송 우선 표시
* 온라인 / 오프라인 상태 표시
* 온라인 방송 상태 새로고침
* 그룹별 온라인 방송을 한 번에 멀티뷰에 추가
* 즐겨찾기 방송을 클릭하여 현재 멀티뷰에 추가
* `그룹 관리` 기능 제공
* `항목 관리` 기능 제공

멀티뷰 즐겨찾기 목록은 전체 그룹을 하나의 고정된 조회 영역에서 확인할 수 있으며, 방송 수가 많을 경우 해당 영역 내부에서 스크롤할 수 있습니다.

## 즐겨찾기 관리 구조

즐겨찾기 기능은 **조회 영역**과 **관리 영역**을 분리하여 구성되어 있습니다.

### 그룹 관리

그룹 관리에서는 다음 작업을 수행할 수 있습니다.

* 그룹 추가
* 그룹명 변경
* 그룹 순서 변경
* 그룹 삭제
* `기본 그룹` 관리
* 그룹 삭제 시 방송의 `기본 그룹` 이동

### 항목 관리

항목 관리에서는 전체 즐겨찾기 방송을 기준으로 다음 작업을 수행할 수 있습니다.

* 즐겨찾기 방송 전체 순서 변경
* 드래그 앤 드롭을 통한 순서 변경
* 즐겨찾기 방송의 그룹 변경
* 즐겨찾기 방송 개별 삭제

방송의 전체 순서는 그룹과 별도로 관리되며, 그룹을 변경하더라도 전체 즐겨찾기 순서는 유지됩니다.

## 설치 방법

1. ZIP 파일을 압축 해제합니다.
2. Chrome / Edge / Whale에서 확장 프로그램 관리 페이지를 엽니다.
3. **개발자 모드**를 활성화합니다.
4. **압축해제된 확장 프로그램을 로드**를 선택합니다.
5. 압축 해제한 **CZ 통제실** 폴더를 선택합니다.

---

## 사용 방법

1. 확장 프로그램 팝업을 엽니다.
2. 방송 URL 또는 UID를 입력하여 방송을 추가합니다.
3. 자주 보는 방송은 즐겨찾기에 저장합니다.
4. 필요한 경우 즐겨찾기 그룹을 생성하고 방송을 그룹에 배치합니다.
5. **멀티뷰 열기**를 선택합니다.
6. 멀티뷰 상단바에서 레이아웃, 채팅, 싱크, 볼륨 등을 조절합니다.
7. 레이드 뷰에서는 원하는 방송의 **메인으로 변경** 버튼을 사용하여 메인 방송을 지정합니다.
8. 즐겨찾기 메뉴에서 원하는 방송을 클릭하여 멀티뷰에 추가할 수 있습니다.
9. 그룹에 온라인 방송이 있는 경우 `온라인 N개 멀티뷰` 기능을 사용하여 한 번에 추가할 수 있습니다.
