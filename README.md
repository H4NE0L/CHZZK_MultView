# 치지직 통합관제실

**CHZZK의 여러 방송을 한 화면에서 시청하고 관리하는 브라우저 확장 프로그램**

현재 버전: **v1.1.9** · Chrome / Edge / Naver Whale · Manifest V3

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 멀티뷰 | 기본 레이아웃에서 최대 9개 방송, 레이드 뷰에서 메인 1개와 서브 최대 3개 표시 |
| 방송 관리 | URL·UID로 추가, 목록 삭제·정렬, 메인 방송 지정, 방송 링크 복사 |
| 즐겨찾기 | 그룹·항목 관리, 팝업과 멀티뷰 동기화, 온라인 방송 일괄 추가 |
| 방송 상태 | 온라인·오프라인, 방송 카테고리와 진행 시간 표시 |
| 음량 제어 | 개별·전체 볼륨, 음소거, 메인 방송만 듣기 |
| 싱크 조정 | 라이브 방송별 ±0.1·±0.5초 조정, 지연 표시, 개별·전체 초기화 |
| 채팅·화면 | 채팅창 좌우 전환·열기·닫기, 플레이어 조작 잠금, 상단바 접기 |

## 기능 상세

### 방송 추가와 관리

팝업에 CHZZK 방송 URL 또는 UID를 입력하고 **목록 추가 → 멀티뷰 열기**를 선택합니다. 멀티뷰는 새 CHZZK 탭에서 열리며, 기존에 보고 있던 방송 탭을 대체하지 않습니다.

```text
https://chzzk.naver.com/live/{채널UID}
{채널UID}
```

멀티뷰 입력창에서는 다시보기 주소도 사용할 수 있습니다.

```text
https://chzzk.naver.com/video/{영상ID}
video/{영상ID}
```

방송 목록에서 개별·전체 삭제와 즐겨찾기 등록·해제를 할 수 있습니다. 방송 타일을 드래그해 순서를 바꾸고, 타일의 **메인으로 변경** 버튼으로 메인 방송을 지정합니다. **링크 생성** 버튼으로 방송 링크를 복사할 수 있습니다.

팝업의 목록이 비어 있으면 이전 멀티뷰 방송 목록을 복원합니다. 팝업에 방송을 추가한 상태에서 열면 해당 목록으로 새 멀티뷰를 구성합니다.

### 기본 레이아웃과 레이드 뷰

기본 레이아웃은 방송 수에 맞춰 자동 배치하며 최대 9개까지 표시합니다.

| 표시할 방송 수 | 배치 |
| --- | --- |
| 1개 | 1 × 1 |
| 2개 | 2 × 1 |
| 3~4개 | 2 × 2 |
| 5~6개 | 3 × 2 |
| 7~9개 | 3 × 3 |

레이드 뷰는 메인 방송 1개를 크게, 서브 방송 최대 3개를 작게 표시합니다. 메인 방송을 바꾸면 해당 방송이 메인 위치로 이동합니다. 채팅창이 왼쪽이면 메인도 왼쪽에, 채팅창이 오른쪽이면 메인도 오른쪽에 배치됩니다.

표시 한도를 넘는 방송도 목록에는 유지합니다. 화면에 표시되지 않는 방송은 플레이어를 생성하지 않아 숨겨진 방송의 소리가 재생되지 않습니다. 방송 타일 크기는 브라우저 창과 모니터 크기에 맞춰 조정됩니다.

### 즐겨찾기와 그룹

팝업과 멀티뷰는 같은 즐겨찾기 저장소를 사용합니다. 한 화면에서 변경한 그룹·항목은 다른 열린 화면에도 반영되며, 브라우저를 다시 시작해도 저장됩니다.

- **조회 화면:** 그룹별 방송 확인, 그룹 접기·펼치기, 방송 클릭으로 목록에 추가
- **그룹 관리:** 그룹 추가·이름 변경·삭제·드래그 정렬
- **항목 관리:** 즐겨찾기 전체 순서 변경·그룹 이동·개별 삭제

드래그 중인 행은 흐리게 표시되고 놓을 위치는 초록색 테두리로 강조됩니다. 이동한 행에는 완료 강조 애니메이션이 표시됩니다. 드래그 중 저장소가 변경되어도 관리 화면의 행을 다시 만들지 않아 조작을 유지합니다.

`기본 그룹`은 삭제할 수 없습니다. 사용자 그룹을 삭제하면 포함된 방송은 기본 그룹으로 이동합니다. 비어 있는 그룹도 저장되며, 방송의 그룹을 바꾸더라도 즐겨찾기의 전체 순서는 유지됩니다.

### 온라인 상태와 방송 정보

즐겨찾기는 그룹 안에서 온라인 방송을 우선 표시합니다. 같은 온라인 상태의 방송끼리는 저장된 전체 순서를 따릅니다.

즐겨찾기 항목은 **스트리머명(아래에 카테고리) · 사람 아이콘과 시청자 수 · 방송시간(`hh:mm:ss 스트리밍 중`)**를 표시합니다. 온라인 방송의 카테고리는 이름 아래 작은 초록색 글씨로 왼쪽에 1px 여백을 두고 표시합니다. 방송시간은 굵은 글씨로 왼쪽 정렬, 시청자 수는 빨간색 글씨로 오른쪽 정렬합니다. 오프라인 방송은 상태 점과 스트리머명만 표시합니다. ONLINE/OFFLINE 문구는 숨기고 상태 점으로 온라인 여부를 표시합니다. 긴 이름과 카테고리는 말줄임 처리하며, 온라인 방송에서 조회되지 않은 시간·시청자 수는 `--`로 표시합니다. 시청자 수는 `명` 대신 사람 아이콘과 숫자로 표시하며, 이름·시청자 수·방송시간 칸은 **30:25:45 고정 비율**로 나눠 한 줄을 유지합니다. 그룹 제목은 `그룹명 (인원 수)` 형태로 왼쪽에 붙여 표시하며 빈 그룹도 `(0)`을 표시합니다. **새로고침**으로 상태를 갱신하고, 그룹의 **온라인 N개 멀티뷰** 버튼으로 온라인 방송을 한 번에 추가할 수 있습니다.

방송 시간은 저장된 시작 시각을 기준으로 매초 갱신합니다. 열린 화면은 30초마다 방송 상태·시청자 수를 조회해 방송 종료를 자동 반영합니다. 브라우저가 백그라운드 타이머를 제한하면 조회가 늦어질 수 있습니다. 조회 실패 시 기존 상태를 유지하며, 수동 새로고침도 사용할 수 있습니다. 온라인 상태 자체는 CHZZK API 조회 결과를 사용합니다. 조회 중 즐겨찾기를 편집해도 응답을 방송 UID로 연결하며, 상태 조회가 그룹과 순서를 덮어쓰지 않습니다.

확장 업데이트로 기존 탭의 확장 연결이 끊기면 조회와 그룹·항목 변경은 가능한 범위에서 현재 화면에 적용하며, 저장·다른 화면 동기화가 불가능하다는 안내를 표시합니다. 이 상태의 변경은 저장된 것으로 간주하지 마세요.

### 볼륨과 음소거

방송별 볼륨과 전체 볼륨을 따로 조절합니다. 실제 음량은 `방송별 볼륨 × 전체 볼륨`으로 적용하며, 전체 볼륨을 바꿔도 개별 볼륨 설정은 유지합니다.

방송별 음소거를 해제하면 이전 볼륨으로 돌아갑니다. CHZZK 플레이어에서 직접 바꾼 음량·음소거 상태도 통합관제실에 반영됩니다. **메인만 듣기**를 켜면 메인 방송의 소리만 재생하며, 기존 방송별 음소거 설정은 별도로 유지합니다.

### 싱크 조정

상단의 **싱크** 메뉴에서 라이브 방송별 재생 위치를 조절합니다.

| 버튼 | 동작 |
| --- | --- |
| `-0.1`, `-0.5` | 뒤로 되감아 지연 증가 |
| `+0.1`, `+0.5` | 라이브 끝에 더 가깝게 이동 |
| `초기화` | 해당 방송의 누적 조정값 초기화 |
| `전체 초기화` | 모든 방송의 누적 조정값 초기화 |

방송별 조정값·지연값과 조정된 방송 수를 표시합니다. 재생 가능한 범위를 넘으면 일부만 적용되거나 적용되지 않을 수 있습니다. 지연값은 재생 위치와 라이브 끝 사이의 거리이며, 방송자의 실제 송출 지연과는 다를 수 있습니다.

싱크 조정값은 저장되지 않고 플레이어가 다시 로드되면 0초로 돌아갑니다. 다시보기에는 싱크 조정을 지원하지 않습니다.

### 채팅과 화면 제어

메인 방송의 채팅창을 열거나 닫고 좌우 위치를 바꿀 수 있습니다. 다시보기는 CHZZK에서 제공하는 라이브 채팅 다시보기를 불러옵니다.

플레이어에 넓은 화면 모드를 자동 적용하며, 타일 컨트롤은 마우스를 올리면 표시됩니다. **화면 잠금**으로 플레이어 조작을 막아도 방송 관리 기능은 계속 사용할 수 있습니다. 상단바를 접어 영상 영역을 넓힐 수도 있습니다.

## 설치와 사용 환경

### 지원 환경

Chrome·Microsoft Edge·Naver Whale의 Manifest V3 지원 버전에서 사용합니다. 방송·채팅·상태 조회에는 인터넷과 CHZZK 서비스 접속이 필요합니다. 로그인된 CHZZK 환경을 지원하며, 로그인이 필요한 콘텐츠는 브라우저에서 Naver 로그인을 먼저 진행하세요.

사용을 위한 Node.js 설치나 빌드, 별도 서버 실행은 필요하지 않습니다.

### 설치

1. 배포 ZIP 또는 GitHub의 **Code → Download ZIP**으로 파일을 받고 압축을 해제합니다.
2. 브라우저의 확장 관리 페이지를 엽니다. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`입니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드**를 선택합니다.
4. `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 툴바의 **치지직 통합관제실** 아이콘을 열고 방송을 추가합니다.

### 업데이트

기존에 로드한 폴더에서 코드를 업데이트한 뒤 확장 관리 페이지에서 **다시 로드**하고 CHZZK 탭도 새로고침하세요. v1.1.8의 즐겨찾기 저장소 키를 유지하므로 같은 확장으로 업데이트하면 기존 데이터를 계속 읽습니다.

다른 폴더를 새 확장으로 로드하면 확장 ID가 달라 별도 저장소를 사용할 수 있습니다. 기존 즐겨찾기를 유지하려면 원래 설치 폴더를 사용하세요.

### 확장 권한

| 권한 | 사용 목적 |
| --- | --- |
| `storage` | 즐겨찾기·그룹·멀티뷰 상태 저장과 동기화 |
| `tabs` | 멀티뷰를 새 탭으로 열기 |
| `scripting` | 콘텐츠 스크립트 주입이 지연될 때 실행 보완 |
| `cookies` | Naver 로그인 세션을 플레이어 환경에 연결 |
| CHZZK·Naver 호스트 접근 | 방송·채팅·API 조회 및 로그인 연동 |

## 프로젝트 구조

| 파일·폴더 | 역할 |
| --- | --- |
| `manifest.json` | 확장 정보·권한·스크립트 실행 순서 |
| `background.js` | 서비스 워커, 새 멀티뷰 탭 열기, 로그인 쿠키 연동 |
| `popup.html` / `popup.css` / `popup.js` | 팝업 화면과 방송·즐겨찾기 관리 |
| `chzzk-page.js` | CHZZK 최상위 페이지의 멀티뷰 UI·방송·채팅·싱크 제어 |
| `chzzk-frame.js` | 방송·채팅 프레임의 플레이어 제어와 상태 전달 |
| `favorites-store.js` | 공용 즐겨찾기 데이터 처리·방송 정보 조회·저장·변경 감지 |
| `icon16/32/48/128.png` | 확장 아이콘 |
| `tests/` | 데이터·스크립트 주입 회귀 테스트와 브라우저 DOM 검사 |
| `README.md` | 기능·설치·개발 안내 |
| `CHANGELOG.md` | 버전별 변경 이력 |

팝업과 멀티뷰의 UI·이벤트 처리는 각 파일에서 담당하고, 공통 데이터 로직은 `favorites-store.js`에서 담당합니다. 콘텐츠 스크립트는 공용 모듈을 먼저 불러오며, 대체 주입 경로에서도 같은 순서를 사용합니다. 배포 ZIP은 실행 파일·아이콘·문서 총 14개로 구성하고 `tests/`는 제외합니다.

## 개발과 검증

저장소 폴더를 확장으로 로드해 개발합니다. 수정한 뒤 확장을 다시 로드하고 CHZZK 페이지를 새로고침하세요.

Node.js 18 이상에서 데이터·스크립트 주입 회귀 테스트를 실행합니다.

```sh
node --test tests/*.test.cjs
```

Playwright와 Chromium이 설치된 개발 환경에서는 브라우저 DOM 검사를 실행합니다. `CHROMIUM_PATH`로 Chromium 실행 파일을 지정할 수 있습니다.

```sh
node tests/browser-smoke.cjs
```

브라우저 검사는 팝업과 멀티뷰의 양방향 동기화, 그룹·항목 관리, 드래그 순서, 빈 그룹 보존, 플레이어 프레임 유지와 싱크 UI를 확인합니다. Chrome API와 CHZZK 응답은 모의 구현이므로 실제 확장 등록·로그인·방송 재생을 대신하지 않습니다.

배포 전 실제 브라우저에서 기존 데이터 복원, 두 화면 간 동기화, 방송·채팅, 메인 변경·레이드 뷰, 볼륨·음소거와 싱크 조정·초기화를 확인하세요.
