# 치지직 통합관제실

여러 CHZZK 방송을 한 화면에서 시청하고 관리하는 브라우저 확장 프로그램입니다.

**v2.0.3** · Chrome 119 이상 / 최신 Edge·Naver Whale

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 멀티뷰 | 최대 9개 방송 시청, 메인 방송을 크게 보는 레이드 뷰 |
| 즐겨찾기·그룹 | 방송 등록, 그룹 편집·순서 변경, 온라인 방송 한 번에 열기 |
| 팔로잉 | 로그인한 계정의 온라인 방송 조회·이름/카테고리 검색, ↻ 버튼으로 새로고침 |
| 음량·싱크 | 개별·전체 볼륨, 메인만 듣기, 방송 간 재생 싱크 조정 |
| 채팅 | 메인 방송의 채팅·주요 사용자 채팅 모음, 좌우 위치 변경 |
| 스크린샷 | 영역 선택 후 PNG 복사·저장 |
| 녹화 | 지원되는 MP4/WebM 형식으로 전체 또는 선택 구간 저장 |
| 재생 탐색 | 방향키와 재생바로 재생 가능한 구간 이동 |

## 설치

1. GitHub의 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. `chrome://extensions`에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드**하고 `manifest.json`이 있는 폴더를 선택합니다.

별도 서버나 Node.js 설치는 필요하지 않습니다. 팔로잉과 로그인이 필요한 방송은 Naver 로그인 후 이용하세요.

## 사용 방법

1. 확장 아이콘을 눌러 CHZZK 방송 URL 또는 채널 UID를 입력합니다. 다시보기 URL도 사용할 수 있습니다.
2. **목록 추가 → 새 탭으로 열기 / 새 창으로 열기**를 선택합니다.
3. 타일을 드래그해 순서를 바꾸고 **메인으로 변경**으로 중심 방송을 선택합니다.

치지직 페이지 상단 중앙에 마우스를 올리면 나타나는 **멀티뷰 열기**로 현재 페이지 안에서도 실행할 수 있습니다. 상단 중앙에 마우스를 올리면 나타나는 **치지직으로 돌아가기** 또는 새로고침은 원본 페이지로 돌아가며, 다시 열면 저장된 방송 목록을 복원합니다. 팝업에서 **새 탭으로 열기** 또는 **새 창으로 열기**를 선택할 수 있습니다. 두 방식 모두 기존 멀티뷰를 재사용하지 않고 새로 엽니다. 기존 창은 그대로 유지하며, 복원할 방송 목록·배치·음량 등의 상태는 **가장 최근에 연 멀티뷰**를 기준으로 저장합니다. 예전 창을 조작하거나 닫아도 이 저장 상태를 덮어쓰지 않습니다.

즐겨찾기는 별표로 등록하며 **그룹 관리**에서 편집합니다. 메인 화면의 즐겨찾기·팔로잉에서 현재 멀티뷰에 등록한 방송은 초록색 테두리로 표시합니다. 팔로잉은 ↻ 버튼으로 직접 갱신합니다. 방송 목록과 설정은 저장되며, 멀티뷰 페이지를 새로고침해도 복원됩니다. 단, 처음 열거나 새로고침하여 방송을 복원할 때 타일은 볼륨 10%·음소거로 시작합니다.

### 단축키

| 키 | 동작 |
| --- | --- |
| **S** | 스크린샷 미리보기 열기 |
| **R** | 녹화 시작·종료 |
| **F** | 즐겨찾기 열기·닫기 |
| **H** | 화면 잠금·해제 |
| **B** | 상단바 접기·펴기 |
| **V** | 소리 조절 패널 열기·닫기 |
| **G** | 그리드·레이드 뷰 전환 |
| **C** | 채팅 열기·닫기 |
| **← / →** | 3초 뒤로·앞으로 이동 |

멀티뷰 화면에서는 메인 방송, 플레이어 안에서는 해당 방송에 적용됩니다. 채팅·검색 입력 중에는 동작하지 않습니다. 재생바는 타일에 마우스를 올리면 표시됩니다.

상단 오른쪽 **설정 → 멀티뷰 단축키 사용**에서 F/H/B/V/G/C와 방향키를 켜거나 끌 수 있습니다. 설정은 저장되며 S/R은 이 설정과 무관하게 사용할 수 있습니다.

소리를 켜거나 음량을 올리면 멀티뷰 탭 자체의 음소거도 해제합니다. 사이트의 자동 음량 변경은 타일 설정에 반영하지 않고 지정한 값으로 복구합니다.

### 캡처·녹화 안내

- 스크린샷 창은 이동할 수 있고 열린 상태에서도 멀티뷰를 조작할 수 있습니다. 여러 장은 좌우로 넘겨 선택합니다. 자르기는 기본 OFF이며 좌측 하단 **자르기** 버튼을 켜서 영역을 조절합니다. 저장 후에도 목록은 유지됩니다.
- 녹화 종료 후 형식과 저장 구간을 선택합니다. 파일명은 `[YY.MM.DD]이름_방송제목`이며 구간 저장 시 `_X-Ys`가 붙습니다. 미지원 형식은 비활성화됩니다.
- 녹화는 방송당 **256MB**에서 자동 중지됩니다. 구간 저장·형식 변환은 선택한 영상 길이만큼 시간이 걸립니다.
- 진행 중인 녹화는 페이지를 닫거나 새로고침하면 사라질 수 있습니다. 결과 창을 닫으면 저장하지 않은 임시 영상도 삭제됩니다.

채팅을 닫으면 채팅 프레임을 종료해 불필요한 수신·처리를 줄입니다. 다시 열면 새로 연결하며 이전 채팅 내역과 입력 중인 내용은 유지되지 않습니다.

### 주요 채팅

채팅 헤더는 **스트리머 이름 → 채널 열기 → 주요 채팅 설정 → 치지직 설정** 순서입니다. 채널 열기는 현재 방송을 새 탭으로 엽니다. 멀티뷰 상단 **설정 → 채팅 모아보기 사용**에서 수집을 켜거나 끕니다. 헤더의 **⚙**에서는 스트리머·관리자·파트너(기본 모두 ON), 닉네임·수집 내용 초기화·모아보기 위치(상단/하단)를 관리합니다. 채팅 열기·닫기와 좌우 위치는 멀티뷰 상단바에서 조작합니다.

수집된 메시지는 시간·닉네임·역할과 함께 카드로 표시하며, 배지와 이모티콘 이미지도 보여줍니다. 별도의 채팅 수집 확장 설치는 필요하지 않습니다.

주요 채팅은 원본 채팅 영역의 일부를 나눠 사용합니다. 상단 배치는 아래 경계, 하단 배치는 위 경계를 드래그해 높이를 조절합니다. 위치와 높이는 저장되며 목록에는 수집된 채팅만 표시합니다. 치지직 사용자 메뉴·설정 팝업과 겹치는 부분은 비워 원본 기능을 조작할 수 있습니다.

최근 100개만 보관하며, 방송 변경·채팅 닫기·필터 변경 시 목록을 비웁니다. 설정은 저장하지만 채팅 내용은 파일에 저장하지 않습니다. 스트리머는 API로 확인한 채널 이름을 대조하며, 역할 배지·표식을 우선 판별합니다. 표식이 없으면 채팅 본문 색상(주황·파랑·초록)을 보조 기준으로 사용하며 닉네임 색은 사용하지 않습니다. 수집되지 않으면 **전체 설정 → 수집 설정·점검 → 점검 정보 복사**로 확인 정보를 복사할 수 있습니다. 읽기·해석·대상·전송·수신·표시 수치와 요소 구조만 포함하며 채팅 내용은 포함하지 않습니다.

### 채팅 수집 확장과 함께 사용

치지직 페이지 안에서 멀티뷰를 열어 기존 확장과 함께 사용할 수 있습니다. 다만 배지 모아 챗·Badge Collector의 멀티뷰 프레임 수집은 아직 검증되지 않았으며, 원본 페이지의 방송만 수집할 수도 있습니다.

채팅 수집 확장을 일반 방송에서 쓰려면 CHZZK 방송을 별도 탭으로 직접 여세요. 멀티뷰 내부의 직접 호환은 각 확장의 iframe 지원 여부에 따라 달라지며 아직 확인되지 않았습니다.

## 업데이트

**기존 설치 폴더**의 파일을 교체하고 확장 관리 페이지에서 **다시 로드**한 뒤 멀티뷰를 새로 여세요. 같은 폴더를 사용해야 기존 즐겨찾기를 유지할 수 있습니다.

## 최근 변경 사항

### v2.0.3

- 팝업에서 새 탭·새 창을 선택하고 가장 최근에 연 멀티뷰의 상태를 기억합니다.
- 주요 사용자 채팅 수집, 배지·이모티콘 카드 표시, 높이 조절과 수집 설정·점검을 추가했습니다.
- 타일별 음량·음소거 동기화를 보완하고 주소 복사를 일반 URL로 변경했습니다.

### v2.0.2

치지직 페이지 안에서 열기, 이동 가능한 스크린샷 갤러리, 녹화 파일명 정리와 사용 중인 방송 표시를 추가했습니다. 방송 복원 시 타일은 10%·음소거로 시작하며, 채팅을 닫으면 프레임을 종료합니다.

자세한 변경 이력은 [CHANGELOG](CHANGELOG.md)를 참고하세요.
