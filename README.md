# CZ 통제실 v1.1.6

**CHZZK 방송 통합관제 시스템**

CHZZK의 여러 방송을 한 화면에서 동시에 시청하고 관리할 수 있도록 만든 Chrome / Edge / Whale용 Manifest V3 확장 프로그램입니다.

------------------------------------------------------------------------

## 주요 기능

### 방송 관리

-   CHZZK 방송 URL 또는 UID로 방송 추가
-   다시보기 영상 URL 지원
    -   `https://chzzk.naver.com/video/{영상ID}`
    -   `video/{영상ID}`
-   현재 방송 목록 확인
-   개별 방송 삭제 / 전체 방송 삭제
-   방송 타일 드래그 앤 드롭으로 순서 변경
-   방송 타일의 `메인으로 변경` 버튼으로 메인 방송 지정
-   방송 타일의 `링크 생성` 버튼으로 CHZZK 방송 링크 복사
-   즐겨찾기 등록 및 해제
-   즐겨찾기 그룹 추가 / 이름 변경 / 삭제
-   즐겨찾기 그룹 및 그룹 내 방송 순서 변경
-   즐겨찾기 방송 온라인 / 오프라인 상태 확인
-   로그인된 CHZZK 환경에서 방송 재생 지원

### 멀티뷰 레이아웃

#### 기본 레이아웃

방송 수에 따라 화면을 자동으로 구성합니다.

-   1개: 1×1
-   2개: 2×1
-   3~4개: 2×2
-   5~6개: 3×2
-   7~9개: 3×3
-   최대 9개 방송을 화면에 표시

화면에 표시되지 않는 방송도 방송 목록에서는 삭제되지 않습니다.

#### 레이드 뷰

메인 방송 1개와 서브 방송 최대 3개를 함께 표시합니다.

-   최대 4개 방송 표시
-   메인 방송은 가장 큰 화면에 표시
-   메인 방송 변경 시 해당 방송이 자동으로 메인 위치로 이동
-   채팅창 위치에 따라 `1+3` / `3+1` 배치 자동 전환
-   채팅 왼쪽: 메인 화면 왼쪽 / 서브 화면 오른쪽
-   채팅 오른쪽: 서브 화면 왼쪽 / 메인 화면 오른쪽

## 즐겨찾기

팝업에서 방송을 즐겨찾기로 저장하고 그룹별로 관리할 수 있습니다.

### 그룹 관리

-   즐겨찾기 그룹 추가
-   일반 그룹 삭제
-   `기본 그룹`은 항상 유지
-   그룹 삭제 시 해당 방송은 `기본 그룹`으로 이동
-   그룹 접기 / 펼치기
-   전체 그룹 또는 특정 그룹만 보기
-   그룹을 드래그하여 그룹 순서 변경

### 방송 관리

-   그룹 내 즐겨찾기 방송 순서 변경
-   방송 항목을 드래그하여 순서 변경
-   즐겨찾기 방송의 그룹 이동
-   즐겨찾기 개별 삭제
-   방송의 현재 온라인 / 오프라인 상태 표시
-   온라인 방송을 그룹 내 상단에 우선 표시
-   상태는 팝업을 열 때 갱신하며 수동 새로고침 가능

------------------------------------------------------------------------

## 음량 및 음소거

### 전체 볼륨

확장 프로그램 자체의 전체 볼륨을 조절합니다.

실제 재생 음량은 다음과 같이 적용됩니다.

`방송별 볼륨 × 전체 볼륨`

전체 볼륨을 변경해도 각 방송의 개별 볼륨 설정은 변경되지 않습니다.

### 방송별 볼륨

-   방송별 개별 볼륨 조절
-   방송별 음소거
-   음소거 해제 시 이전 볼륨으로 복귀
-   플레이어에서 직접 변경한 음량/음소거 상태도 통제실 UI에 동기화

### 메인만 듣기

`메인만 듣기`를 활성화하면 메인 방송의 소리만 들을 수 있습니다.

기존 방송별 음소거 설정은 별도로 유지됩니다.

------------------------------------------------------------------------

## 채팅

-   각 방송에 대응하는 채팅 패널 제공
-   채팅창 열기 / 닫기
-   채팅창 좌 / 우 위치 변경
-   레이드 뷰에서 채팅 위치에 맞춰 메인/서브 영상 배치도 자동 변경
-   다시보기의 경우 CHZZK에서 제공하는 **라이브 채팅 다시보기**를 채팅 패널에서 불러옴

------------------------------------------------------------------------

## 화면 및 UI

-   방송 타일은 CHZZK 플레이어의 넓은 화면 모드를 자동 적용
-   모니터 해상도와 브라우저 창 크기에 맞춰 타일 크기 자동 조정
-   방송 및 채팅 영역의 불필요한 스크롤바 방지
-   상단바 접기 / 펼치기
-   화면 잠금 기능
    -   플레이어 조작을 방지
    -   통제실의 방송 관리 기능은 계속 사용할 수 있음
-   방송 타일 상단 컨트롤은 평소 숨겨지고 타일에 마우스를 올리면 표시

------------------------------------------------------------------------

## 팝업

확장 프로그램 팝업에서는 다음 기능을 제공합니다.

-   현재 확장 프로그램 버전 표시
-   방송 URL / UID 입력
-   저장된 방송 목록 관리
-   즐겨찾기 관리
-   즐겨찾기 그룹 관리
-   즐겨찾기 온라인 상태 확인
-   멀티뷰 열기

팝업에서 특정 멀티뷰 목록을 선택하지 않고 멀티뷰를 열면 이전에 사용하던 멀티뷰 방송 목록을 복원할 수 있습니다.

------------------------------------------------------------------------

## 즐겨찾기 관리

팝업과 멀티뷰에서 동일한 즐겨찾기 데이터를 사용합니다.

-   즐겨찾기 방송은 `기본 그룹` 또는 사용자가 만든 그룹에 배치할 수 있습니다.
-   그룹 이름 변경 및 그룹 삭제가 가능합니다.
-   그룹 삭제 시 해당 방송은 `기본 그룹`으로 이동합니다.
-   그룹 순서를 드래그하여 변경할 수 있습니다.
-   그룹 안의 방송 순서를 드래그하여 변경할 수 있습니다.
-   온라인 방송은 `ONLINE`으로 표시되며 목록에서 우선 확인할 수 있습니다.
-   새로고침을 통해 현재 온라인 상태를 다시 확인할 수 있습니다.
-   즐겨찾기와 그룹 정보는 브라우저/PC를 종료해도 유지됩니다.

## 설치 방법

1.   ZIP 파일을 압축 해제합니다.
2.   Chrome / Edge / Whale에서 확장 프로그램 관리 페이지를 엽니다.
3.   **개발자 모드**를 활성화합니다.
4.   **압축해제된 확장 프로그램을 로드**를 선택합니다.
5.   압축 해제한 **CZ 통제실** 폴더를 선택합니다.

------------------------------------------------------------------------

## 사용 방법

1.   확장 프로그램 팝업을 엽니다.
2.   방송 URL 또는 UID를 입력하여 방송을 추가합니다.
3.   자주 보는 방송은 즐겨찾기에 저장하고 필요하면 그룹을 지정합니다.
4.   **멀티뷰 열기**를 선택합니다.
5.   멀티뷰 상단바에서 레이아웃, 채팅, 볼륨 등을 조절합니다.
6.   레이드 뷰에서는 원하는 방송의 **메인으로 변경** 버튼을 사용하여 메인 방송을 지정합니다.

| `multiview.css` | 멀티뷰 스타일 |
