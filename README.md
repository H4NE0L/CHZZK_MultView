# 치지직 통합관제실

여러 CHZZK 방송을 한 화면에서 시청하는 브라우저 확장 프로그램입니다.

**v3.1.1 · Chrome 119 이상 권장**

## 주요 기능

- 최대 9개 방송, 그리드·레이드 배치와 개별·전체 음량 조절
- 즐겨찾기·그룹 관리, 팔로잉 검색과 온라인 방송 열기
- 원본 채팅과 주요 사용자 채팅 모아보기 — 접힌 동안에도 수집 유지
- 스크린샷 자르기·복사·저장, MP4/WebM 녹화와 구간 저장
- 설정·즐겨찾기 JSON 백업과 복원

## 설치 및 업데이트

1. **[설치용 ZIP 다운로드](https://github.com/H4NE0L/CHZZK_MultView/raw/refs/heads/release/CZ-Control-Room-v3.1.1.zip)** 후 압축을 풉니다.
2. `chrome://extensions`에서 **개발자 모드 → 압축해제된 확장 프로그램을 로드**를 선택합니다.
3. 압축을 푼 폴더 중 `manifest.json`이 있는 폴더를 지정합니다.

업데이트는 먼저 설정을 백업하고 **기존 설치 폴더**에 파일을 교체한 뒤 확장을 다시 로드하세요. 다른 폴더에 새로 등록하면 저장 데이터 이전이 필요할 수 있습니다.

GitHub **main은 개발 소스**, **release는 빌드된 설치 파일**입니다. main의 Code → Download ZIP은 바로 설치할 수 없습니다. release 브랜치의 Code → Download ZIP으로 받아도 설치할 수 있습니다. 설치 파일은 Node.js나 별도 서버 없이 사용할 수 있습니다.

## 사용 방법

확장 아이콘에서 방송 URL·UID를 추가하고 **새 탭 / 새 창으로 열기**를 선택합니다. 치지직 페이지 상단 중앙에 마우스를 올려 **멀티뷰 열기**로도 실행할 수 있습니다.

설정 → 플레이어에서 스크린샷·영상 파일명 형식을 각각 지정할 수 있습니다. `{channel}`은 방송인, `{title}`은 방송 제목, `{date}`·`{time}`은 PC의 현지 날짜·시각이며 확장자는 자동으로 붙습니다.

싱크 메뉴의 **최신으로 / 전체 최신으로**는 재생 가능한 최신 지점까지 당깁니다.

가장 최근에 연 멀티뷰의 목록·배치·설정을 기억합니다. 처음 열거나 새로고침하면 타일은 **볼륨 10%·음소거**로 시작합니다. 팔로잉과 회원 방송은 Naver 로그인이 필요합니다.

| 단축키 | 기능 |
| --- | --- |
| S / R | 스크린샷 / 녹화 시작·종료 |
| F / V / G | 즐겨찾기 / 볼륨 패널 / 배치 전환 |
| H / B / C | 화면 잠금 / 상단바 / 채팅 |
| ← / → | 재생 가능한 구간에서 3초 이동 |

입력 중에는 단축키가 동작하지 않습니다. S/R을 제외한 단축키는 설정에서 끌 수 있습니다.

## 설정과 제한

- **설정 내보내기 / 불러오기**는 전체 설정 최상단에 있습니다. 선택한 프로젝트 폴더의 `.backup`에 저장합니다. [백업·복원 안내](docs/settings-backup.md)
- 멀티뷰 설정: **편의기능**(통나무 수집), **멀티뷰**(단축키·배치), **플레이어**(녹화·되감기 바·자동 넓은 화면), **채팅**(모아보기·위치·펼치기). 설정 백업은 상단에 둡니다.
- OFFLINE 타일은 초록색 새로고침 버튼으로 즉시 확인할 수 있습니다. 30초마다 상태를 확인해 ONLINE으로 바뀌면 해당 타일만 재연결합니다. 녹화 중에는 재연결을 보류합니다.
- 모아보기 헤더의 톱니에서 **기본 채팅 / 모아보기** 설정을 구분합니다. 두 영역의 배지 표시는 독립적이며, 기본 채팅의 배지를 끄면 아이콘과 빈 공간까지 사라집니다. 수집 결과는 유지됩니다.
- 수집은 활성화·대상 추가 이후의 새 채팅부터 시작합니다. 사용자 정보 메뉴에서도 수집 대상을 추가·삭제할 수 있습니다. 보관 개수 제한은 없으며 화면은 300개씩 이전/다음/최신으로 탐색합니다.
- 모아보기 헤더의 카메라 버튼에서 전체 또는 선택한 메시지를 PNG로 저장합니다. 이미지 로드 실패 시 대체 표시하며 수집 목록은 지우지 않습니다.
- **채팅 타임스탬프는 실험 기능·기본 OFF**입니다. 채팅 설정의 기본 채팅 탭에서 ON/OFF할 수 있으며 켜도 원본 작성 시각이 확인되는 메시지만 표시합니다.
- **통나무 수집 보조는 실험 기능·기본 OFF**입니다. 화면 모드를 바꾸지 않고 원본 보너스 버튼만 처리합니다. 실제 적립·수령은 치지직 조건과 버튼 제공 여부에 따릅니다. [점검 안내](docs/power-diagnostics.md)
- 스크린샷은 최대 12장·128MiB, 녹화는 방송당 256MiB까지 보관합니다. 결과 창을 닫기 전에 저장하세요. 코덱 지원은 브라우저에 따라 다릅니다.
