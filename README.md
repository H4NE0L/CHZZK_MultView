# 치지직 통합관제실

여러 CHZZK 방송을 한 화면에서 시청하고 관리하는 브라우저 확장 프로그램입니다.

**v2.0.2** · Chrome 119 이상 / 최신 Edge·Naver Whale

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 멀티뷰 | 최대 9개 방송 시청, 메인 방송을 크게 보는 레이드 뷰 |
| 즐겨찾기·그룹 | 방송 등록, 그룹 편집·순서 변경, 온라인 방송 한 번에 열기 |
| 팔로잉 | 로그인한 계정의 온라인 방송 조회·이름/카테고리 검색, ↻ 버튼으로 새로고침 |
| 음량·싱크 | 개별·전체 볼륨, 메인만 듣기, 방송 간 재생 싱크 조정 |
| 채팅 | 메인 방송의 채팅 표시, 좌우 위치 변경 |
| 스크린샷 | 영역 선택 후 PNG 복사·저장 |
| 녹화 | 지원되는 MP4/WebM 형식으로 전체 또는 선택 구간 저장 |
| 재생 탐색 | 방향키와 재생바로 재생 가능한 구간 이동 |

## 설치

1. GitHub의 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. `chrome://extensions`에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드**하고 `manifest.json`이 있는 폴더를 선택합니다.

별도 서버나 Node.js 설치는 필요하지 않습니다. 팔로잉과 로그인이 필요한 방송은 Naver 로그인 후 이용하세요.

## 사용 방법

1. 확장 아이콘을 눌러 CHZZK 방송 URL 또는 채널 UID를 입력합니다. 다시보기 URL도 사용할 수 있습니다.
2. **목록 추가 → 멀티뷰 열기**를 선택합니다.
3. 타일을 드래그해 순서를 바꾸고 **메인으로 변경**으로 중심 방송을 선택합니다.

치지직 페이지 상단 중앙에 마우스를 올리면 나타나는 **멀티뷰 열기**로 현재 페이지 안에서도 실행할 수 있습니다. 상단 중앙에 마우스를 올리면 나타나는 **치지직으로 돌아가기** 또는 새로고침은 원본 페이지로 돌아가며, 다시 열면 저장된 방송 목록을 복원합니다. 팝업에서는 기존처럼 별도 페이지로 엽니다.

즐겨찾기는 별표로 등록하며 **그룹 관리**에서 편집합니다. 메인 화면의 즐겨찾기·팔로잉에서 현재 멀티뷰에 등록한 방송은 초록색 테두리로 표시합니다. 팔로잉은 ↻ 버튼으로 직접 갱신합니다. 방송 목록과 설정은 저장되며, 멀티뷰 페이지를 새로고침해도 복원됩니다. 단, 처음 열거나 새로고침하여 방송을 복원할 때 타일은 볼륨 10%·음소거로 시작합니다.

### 단축키

| 키 | 동작 |
| --- | --- |
| **S** | 스크린샷 미리보기 열기 |
| **R** | 녹화 시작·종료 |
| **F** | 즐겨찾기 열기·닫기 |
| **H** | 화면 잠금·해제 |
| **B** | 상단바 접기·펴기 |
| **V** | 소리 조절 패널 열기·닫기 |
| **G** | 그리드·레이드 뷰 전환 |
| **C** | 채팅 열기·닫기 |
| **← / →** | 3초 뒤로·앞으로 이동 |

멀티뷰 화면에서는 메인 방송, 플레이어 안에서는 해당 방송에 적용됩니다. 채팅·검색 입력 중에는 동작하지 않습니다. 재생바는 타일에 마우스를 올리면 표시됩니다.

상단 오른쪽 **설정 → 멀티뷰 단축키 사용**에서 F/H/B/V/G/C와 방향키를 켜거나 끌 수 있습니다. 설정은 저장되며 S/R은 이 설정과 무관하게 사용할 수 있습니다.

### 캡처·녹화 안내

- 스크린샷 창은 이동할 수 있고 열린 상태에서도 멀티뷰를 조작할 수 있습니다. 여러 장은 좌우로 넘겨 선택합니다. 자르기는 기본 OFF이며 좌측 하단 **자르기** 버튼을 켜서 영역을 조절합니다. 저장 후에도 목록은 유지됩니다.
- 녹화 종료 후 형식과 저장 구간을 선택합니다. 파일명은 `[YY.MM.DD]이름_방송제목`이며 구간 저장 시 `_X-Ys`가 붙습니다. 미지원 형식은 비활성화됩니다.
- 녹화는 방송당 **256MB**에서 자동 중지됩니다. 구간 저장·형식 변환은 선택한 영상 길이만큼 시간이 걸립니다.
- 진행 중인 녹화는 페이지를 닫거나 새로고침하면 사라질 수 있습니다. 결과 창을 닫으면 저장하지 않은 임시 영상도 삭제됩니다.

채팅을 닫으면 채팅 프레임을 종료해 불필요한 수신·처리를 줄입니다. 다시 열면 새로 연결하며 이전 채팅 내역과 입력 중인 내용은 유지되지 않습니다.

### 채팅 수집 확장과 함께 사용

치지직 페이지 안에서 멀티뷰를 열어 기존 확장과 함께 사용할 수 있습니다. 다만 배지 모아 챗·Badge Collector의 멀티뷰 프레임 수집은 아직 검증되지 않았으며, 원본 페이지의 방송만 수집할 수도 있습니다.

채팅 영역의 **원본 방송 열기**를 누르면 일반 CHZZK 방송을 별도 음소거 탭으로 엽니다. 배지 모아 챗·Badge Collector 등 기존 확장의 수집 화면은 원본 탭에서 확인하세요. 멀티뷰 내부의 직접 호환은 각 확장의 iframe 지원 여부에 따라 달라지며 아직 확인되지 않았습니다.

## 업데이트

**기존 설치 폴더**의 파일을 교체하고 확장 관리 페이지에서 **다시 로드**한 뒤 멀티뷰를 새로 여세요. 같은 폴더를 사용해야 기존 즐겨찾기를 유지할 수 있습니다.

## v2.0.2 변경 사항

치지직 페이지 상단 중앙에 마우스를 올려 **멀티뷰 열기**로 실행할 수 있습니다. 방송 복원 시 타일은 10%·음소거로 시작합니다. 스크린샷은 이동 가능한 갤러리에서 여러 장을 선택·자르기·저장하며, 녹화 파일명은 `[YY.MM.DD]이름_방송제목`으로 변경했습니다. 메인 목록에서 사용 중인 방송을 초록색 테두리로 표시합니다. 채팅을 닫으면 프레임을 종료하고 다시 열 때 새로 연결합니다.

### v2.0.1

설정과 F/H/B/V/G/C 단축키, 팔로잉 이름·카테고리 검색을 추가하고 배치 이름을 **그리드**로 변경했습니다.
