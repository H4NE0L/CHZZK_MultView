# 치지직 통합관제실

**CHZZK의 여러 방송을 한 화면에서 시청하고 관리하는 브라우저 확장 프로그램**

개발 버전: **v2.0.0** · 안정 버전: **v1.1.9 (main)** · Chrome / Edge / Naver Whale · Manifest V3

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 멀티뷰 | 기본 레이아웃에서 최대 9개 방송, 레이드 뷰에서 메인 1개와 서브 최대 3개 표시 |
| 방송 관리 | URL·UID로 추가, 목록 삭제·정렬, 메인 방송 지정, 방송 링크 복사 |
| 즐겨찾기 | 통합 그룹 관리, 팔로잉 체크 선택, 그룹 순서·다중 소속, 온라인 방송 일괄 추가 |
| 팔로잉 | 로그인한 계정의 팔로잉 조회·검색·온라인 표시, 박스 접기·펼치기 |
| 방송 상태 | 온라인·오프라인, 방송 카테고리와 진행 시간 표시 |
| 음량 제어 | 개별·전체 볼륨, 음소거, 메인 방송만 듣기 |
| 싱크 조정 | 라이브 방송별 ±0.1·±0.5초 조정, 지연 표시, 개별·전체 초기화 |
| 채팅·화면 | 채팅창 좌우 전환·열기·닫기, 플레이어 조작 잠금, 상단바 접기 |

## 기능 상세

### 방송 추가와 관리

팝업에 CHZZK 방송 URL 또는 UID를 입력하고 **목록 추가 → 멀티뷰 열기**를 선택합니다. 멀티뷰는 전용 확장 페이지 탭에서 열립니다. 이미 열린 멀티뷰 탭이 있으면 재사용하며, 일반 CHZZK 탭은 변경하지 않습니다. 팝업 목록이 비어 있으면 기존 목록을 유지하고, 목록을 지정하면 해당 방송 목록으로 바꿉니다.

```text
https://chzzk.naver.com/live/{채널UID}
{채널UID}
```

팝업과 멀티뷰 입력창에서는 다시보기 주소도 사용할 수 있습니다.

```text
https://chzzk.naver.com/video/{영상ID}
video/{영상ID}
```

방송 목록에서 개별·전체 삭제와 즐겨찾기 등록·해제를 할 수 있습니다. 방송 타일을 드래그해 순서를 바꾸고, 타일의 **메인으로 변경** 버튼으로 메인 방송을 지정합니다. **링크 생성** 버튼으로 방송 링크를 복사할 수 있습니다.

팝업의 목록이 비어 있으면 이전 멀티뷰 방송 목록을 복원합니다. 팝업에 방송을 추가한 상태에서 열면 해당 목록으로 새 멀티뷰를 구성합니다.

### 기본 레이아웃과 레이드 뷰

기본 레이아웃은 방송 수에 맞춰 자동 배치하며 최대 9개까지 표시합니다.

| 표시할 방송 수 | 배치 |
| --- | --- |
| 1개 | 1 × 1 |
| 2개 | 2 × 1 |
| 3~4개 | 2 × 2 |
| 5~6개 | 3 × 2 |
| 7~9개 | 3 × 3 |

레이드 뷰는 메인 방송 1개를 크게, 서브 방송 최대 3개를 작게 표시합니다. 메인 방송을 바꾸면 해당 방송이 메인 위치로 이동합니다. 채팅창이 왼쪽이면 메인도 왼쪽에, 채팅창이 오른쪽이면 메인도 오른쪽에 배치됩니다.

표시 한도를 넘는 방송도 목록에는 유지합니다. 화면에 표시되지 않는 방송은 플레이어를 생성하지 않아 숨겨진 방송의 소리가 재생되지 않습니다. 방송 타일 크기는 브라우저 창과 모니터 크기에 맞춰 조정됩니다.

### 즐겨찾기와 그룹

팝업과 멀티뷰는 같은 즐겨찾기 저장소를 사용합니다. 한 화면에서 변경한 그룹·항목은 다른 열린 화면에도 반영되며, 브라우저를 다시 시작해도 저장됩니다.

- **조회 화면:** 그룹별 방송 확인, 그룹 접기·펼치기, 방송 클릭으로 목록에 추가
- **그룹 관리:** 그룹 추가·이름 변경·삭제, 위/아래 버튼으로 그룹 순서 변경
- **그룹 편집:** 내 팔로잉 목록에서 이름·제공된 태그를 검색하고 체크해 방송 추가·제외
- **그룹 설정:** 강조색과 오프라인 방송 표시 여부 설정

한 방송을 여러 그룹에 넣을 수 있습니다. 기존 단일 그룹 데이터도 그대로 읽습니다. 항목 관리 메뉴와 항목 간 순서 조정 UI는 보류하며, 기존 항목 순서는 유지합니다. `기본 그룹`은 삭제할 수 없습니다. 그룹 삭제·체크 해제로 다른 소속 그룹이 없어진 방송은 기본 그룹에 남습니다.

### 팔로잉 방송

메인 상단에서는 즐겨찾기 왼쪽에, 팝업에서는 즐겨찾기 아래에 **팔로잉** 박스를 배치합니다. 박스를 접고 펼쳐 공간을 조절하며, 펼치면 현재 Naver 계정의 팔로잉을 조회합니다. 온라인 방송을 우선 표시하고 검색한 방송을 눌러 멀티뷰 목록에 추가할 수 있습니다. 열린 팔로잉 박스는 30초마다 갱신합니다.

로그인이 필요하거나 조회에 실패하면 안내를 표시하고 이전 조회 목록을 유지합니다. 그룹 추가 창에서도 팔로잉을 조회하며, 선택한 방송은 검색어를 바꿔도 유지됩니다. 이름을 지정해 빈 그룹만 만드는 것도 가능합니다.

### 온라인 상태와 방송 정보

즐겨찾기는 그룹 안에서 온라인 방송을 우선 표시합니다. 같은 온라인 상태의 방송끼리는 저장된 전체 순서를 따릅니다.

즐겨찾기 항목은 **스트리머명(옆에 카테고리) · 방송시간(`hh:mm:ss`) · 사람 아이콘과 시청자 수**를 표시합니다. 온라인 방송의 카테고리는 이름 옆에 4px 간격을 둔 10px 초록색 글씨로 표시합니다. 상태 점과 이름 사이에 8px 간격을 두고, 방송시간과 시청자 수 사이 간격은 12px로 유지합니다. 스트리머명은 14px로 표시합니다. 방송시간은 12px 굵은 글씨로 왼쪽 정렬, 시청자 수는 12px 빨간색 글씨로 오른쪽 정렬합니다. 오프라인 방송은 상태 점과 스트리머명만 표시합니다. ONLINE/OFFLINE 문구는 숨기고 상태 점으로 온라인 여부를 표시합니다. 긴 이름과 카테고리는 말줄임 처리하며, 온라인 방송에서 조회되지 않은 시간·시청자 수는 `--`로 표시합니다. 시청자 수는 `명` 대신 사람 아이콘과 숫자로 표시하며, 칸 비율을 고정하지 않고 방송시간·시청자 수는 내용 너비를 확보하며, 남은 공간을 이름·카테고리에 배정해 한 줄을 유지합니다. 그룹 제목은 `그룹명 (인원 수)` 형태로 왼쪽에 붙여 표시하며 빈 그룹도 `(0)`을 표시합니다. **새로고침**으로 상태를 갱신하고, 그룹의 **온라인 N개 멀티뷰** 버튼으로 온라인 방송을 한 번에 추가할 수 있습니다.

방송 시간은 저장된 시작 시각을 기준으로 매초 갱신합니다. 열린 화면은 30초마다 방송 상태·시청자 수를 조회해 방송 종료를 자동 반영합니다. 브라우저가 백그라운드 타이머를 제한하면 조회가 늦어질 수 있습니다. 조회 실패 시 기존 상태를 유지하며, 수동 새로고침도 사용할 수 있습니다. 온라인 상태 자체는 CHZZK API 조회 결과를 사용합니다. 조회 중 즐겨찾기를 편집해도 응답을 방송 UID로 연결하며, 상태 조회가 그룹과 순서를 덮어쓰지 않습니다.

확장 업데이트로 기존 탭의 확장 연결이 끊기면 조회와 그룹·항목 변경은 가능한 범위에서 현재 화면에 적용하며, 저장·다른 화면 동기화가 불가능하다는 안내를 표시합니다. 이 상태의 변경은 저장된 것으로 간주하지 마세요.

### 볼륨과 음소거

방송별 볼륨과 전체 볼륨을 따로 조절합니다. 실제 음량은 `방송별 볼륨 × 전체 볼륨`으로 적용하며, 전체 볼륨을 바꿔도 개별 볼륨 설정은 유지합니다.

방송별 음소거를 해제하면 이전 볼륨으로 돌아갑니다. CHZZK 플레이어에서 직접 바꾼 음량·음소거 상태도 통합관제실에 반영됩니다. **메인만 듣기**를 켜면 메인 방송의 소리만 재생하며, 기존 방송별 음소거 설정은 별도로 유지합니다.

### 싱크 조정

상단의 **싱크** 메뉴에서 라이브 방송별 재생 위치를 조절합니다.

| 버튼 | 동작 |
| --- | --- |
| `-0.1`, `-0.5` | 뒤로 되감아 지연 증가 |
| `+0.1`, `+0.5` | 라이브 끝에 더 가깝게 이동 |
| `초기화` | 해당 방송의 누적 조정값 초기화 |
| `전체 초기화` | 모든 방송의 누적 조정값 초기화 |

방송별 조정값·지연값과 조정된 방송 수를 표시합니다. 재생 가능한 범위를 넘으면 일부만 적용되거나 적용되지 않을 수 있습니다. 지연값은 재생 위치와 라이브 끝 사이의 거리이며, 방송자의 실제 송출 지연과는 다를 수 있습니다.

싱크 조정값은 저장되지 않고 플레이어가 다시 로드되면 0초로 돌아갑니다. 다시보기에는 싱크 조정을 지원하지 않습니다.

### 채팅과 화면 제어

메인 방송의 채팅창을 열거나 닫고 좌우 위치를 바꿀 수 있습니다. 다시보기는 CHZZK에서 제공하는 라이브 채팅 다시보기를 불러옵니다.

플레이어에 넓은 화면 모드를 자동 적용하며, 타일 컨트롤은 마우스를 올리면 표시됩니다. **화면 잠금**으로 플레이어 조작을 막아도 방송 관리 기능은 계속 사용할 수 있습니다. 상단바를 접어 영상 영역을 넓힐 수도 있습니다.

## 최근 버전 주요 변경

### v2.0.0 (개발 중)

- 방송인명은 UID에 대응하는 채널·영상 API에서만 조회합니다. 채팅 닉네임·페이지 DOM·제목을 이름으로 저장하는 경로를 제거하고, 즐겨찾기 갱신 시 기존 잘못된 이름도 API로 보정합니다.

## 설치와 사용 환경

### 지원 환경

Chrome 119 이상 또는 해당 기능을 지원하는 최신 Microsoft Edge·Naver Whale에서 사용합니다. 방송·채팅·상태 조회에는 인터넷과 CHZZK 서비스 접속이 필요합니다. 로그인된 CHZZK 환경을 지원하며, 로그인이 필요한 콘텐츠는 브라우저에서 Naver 로그인을 먼저 진행하세요.

사용을 위한 Node.js 설치나 빌드, 별도 서버 실행은 필요하지 않습니다.

### 설치

1. 배포 ZIP 또는 GitHub의 **Code → Download ZIP**으로 파일을 받고 압축을 해제합니다.
2. 브라우저의 확장 관리 페이지를 엽니다. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`입니다.
3. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드**를 선택합니다.
4. `manifest.json`이 들어 있는 폴더를 선택합니다.
5. 툴바의 **치지직 통합관제실** 아이콘을 열고 방송을 추가합니다.

### 업데이트

기존에 로드한 폴더에서 코드를 업데이트한 뒤 확장 관리 페이지에서 **다시 로드**하세요. v1.1.9의 홈페이지 기반 멀티뷰 탭은 닫고 팝업에서 새 전용 멀티뷰 탭을 여세요. 이후에는 전용 페이지를 새로고침하면 저장된 목록·설정을 복원합니다. v1.1.8의 즐겨찾기 저장소 키를 유지하므로 같은 확장으로 업데이트하면 기존 데이터를 계속 읽습니다.

다른 폴더를 새 확장으로 로드하면 확장 ID가 달라 별도 저장소를 사용할 수 있습니다. 기존 즐겨찾기를 유지하려면 원래 설치 폴더를 사용하세요.

### 확장 권한

| 권한 | 사용 목적 |
| --- | --- |
| `storage` | 즐겨찾기·그룹·멀티뷰 상태 저장과 동기화 |
| `tabs` | 전용 멀티뷰 탭 열기·재사용 |
| `declarativeNetRequestWithHostAccess` | 전용 탭에서 확장이 만든 CHZZK iframe의 삽입 제한 응답 헤더 조정 |
| `cookies` | Naver 로그인 세션을 플레이어 환경에 연결 |
| CHZZK·Naver 호스트 접근 | 방송·채팅·API 조회 및 로그인 연동 |

## 프로젝트 구조

```text
manifest.json
src/
  background/  background.js, viewer-tabs.js
  popup/       popup.html, popup.css, popup.js
  viewer/      viewer.html, viewer.js, viewer.css, page.css
               players.js, audio.js, chat.js, sync.js
  content/     chzzk-frame.js, chat-layout.js
  shared/      chzzk-api.js, favorites-store.js, session-store.js, messages.js
               followings-store.js, group-manager.js, group-manager.css
assets/icons/
tests/
scripts/package.py
```

`viewer.js`는 화면 초기화·레이아웃·즐겨찾기 UI를 연결하며, 플레이어·음량·채팅·싱크 제어는 각 모듈이 담당합니다. `viewer.css`는 기존 Shadow DOM 스타일을 보존하는 별도 파일입니다. 일반 CHZZK 홈페이지에는 멀티뷰 UI를 주입하지 않습니다.

확장 페이지에서 치지직 iframe을 열기 위해 `viewer-tabs.js`는 현재 전용 탭 ID, 확장 initiator, CHZZK 도메인, `sub_frame` 조건을 모두 충족하는 요청에만 CSP·X-Frame-Options 응답 헤더 예외를 적용합니다. 확장 페이지 자체 CSP는 로컬 스크립트와 CHZZK iframe만 허용합니다. 프레임 메시지는 origin과 실제 iframe 창을 함께 검증합니다. 채팅 DOM 정리는 부모에서 접근하지 않고 프레임 내부에서 수행합니다.

즐겨찾기·그룹·세션의 기존 저장소 키는 유지합니다. 전체 볼륨·개별 음량·음소거·메인 방송·레이아웃·채팅 위치·화면 잠금은 복원하고, 싱크 조정값은 현재 플레이어에서만 유지합니다.

## 개발과 검증

저장소 폴더를 확장으로 로드해 개발합니다. 수정한 뒤 확장을 다시 로드하고 전용 멀티뷰 페이지를 새로고침하세요.

Node.js 18 이상에서 데이터·세션·메시지·전용 탭 관리 회귀 테스트를 실행합니다.

```sh
node --test tests/*.test.cjs
```

Playwright와 Chromium이 설치된 개발 환경에서는 브라우저 DOM 검사를 실행합니다. `CHROMIUM_PATH`로 Chromium 실행 파일을 지정할 수 있습니다.

```sh
node tests/browser-smoke.cjs
```

브라우저 검사는 팝업과 멀티뷰의 양방향 동기화, 그룹·항목 관리, 그룹 순서·다중 소속, 팔로잉 조회·로그인 실패 처리, 빈 그룹 보존, 플레이어 프레임 유지와 싱크 UI를 확인합니다. Chrome API와 CHZZK 응답은 모의 구현이므로 실제 확장 등록·DNR 적용·로그인·방송 재생을 대신하지 않습니다.

배포 전 실제 브라우저에서 기존 데이터 복원, 두 화면 간 동기화, 방송·채팅, 메인 변경·레이드 뷰, 볼륨·음소거와 싱크 조정·초기화를 확인하세요.

### 실제 Chrome 확인 순서

1. 기존 설치 폴더에서 v2.0 테스트 브랜치를 받고 확장을 다시 로드합니다. 일반 CHZZK 홈페이지에 멀티뷰가 주입되지 않는지 확인합니다.
2. 팝업에서 방송 2개를 열어 주소가 `chrome-extension://…/src/viewer/viewer.html`인지, 방송·로그인·채팅이 정상인지 확인합니다.
3. 팝업을 다시 열어 멀티뷰 탭이 재사용되는지, 비어 있는 팝업 목록이 기존 방송을 지우지 않는지 확인합니다.
4. 레이드 뷰·메인 방송·개별/전체 볼륨·음소거·채팅 위치·화면 잠금을 바꾸고 새로고침해 복원을 확인합니다. 자동 재생이 브라우저에서 차단되면 플레이어를 눌러 재생합니다.
5. 치지직 플레이어에서 소리를 켠 뒤 다른 타일을 삭제하고, 남은 방송의 소리와 플레이어가 유지되는지 확인합니다.
6. 팔로잉 박스 위치·접기, 실제 로그인 계정의 팔로잉 전체 조회, 검색·온라인 표시를 확인합니다. 그룹 추가·편집에서 체크 선택과 그룹 순서를 확인합니다. 방송 이름이 채팅 시청자 이름으로 바뀌지 않는지, 기존 오염된 이름이 즐겨찾기 새로고침으로 복구되는지 확인합니다.
7. 라이브 싱크 ±0.1/±0.5초, 초기화, 다시보기 채팅, 즐겨찾기·그룹 동기화, 30초 상태 갱신을 확인합니다.
