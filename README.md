# 치지직 통합관제실

여러 CHZZK 방송을 한 화면에서 시청하고 관리하는 브라우저 확장 프로그램입니다.

**v2.0.1 (테스트)** · Chrome 119 이상 / 최신 Edge·Naver Whale

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 멀티뷰 | 최대 9개 방송 시청, 메인 방송을 크게 보는 레이드 뷰 |
| 즐겨찾기·그룹 | 방송 등록, 그룹 편집·순서 변경, 온라인 방송 한 번에 열기 |
| 팔로잉 | 로그인한 계정의 온라인 방송 조회·검색, ↻ 버튼으로 새로고침 |
| 음량·싱크 | 개별·전체 볼륨, 메인만 듣기, 방송 간 재생 싱크 조정 |
| 채팅 | 메인 방송의 채팅 표시, 좌우 위치 변경 |
| 스크린샷 | 영역 선택 후 PNG 복사·저장 |
| 녹화 | 지원되는 MP4/WebM 형식으로 전체 또는 선택 구간 저장 |
| 재생 탐색 | 방향키와 재생바로 재생 가능한 구간 이동 |

## 설치

1. GitHub의 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. `chrome://extensions`에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드**하고 `manifest.json`이 있는 폴더를 선택합니다.

별도 서버나 Node.js 설치는 필요하지 않습니다. 팔로잉과 로그인이 필요한 방송은 Naver 로그인 후 이용하세요.

## 사용 방법

1. 확장 아이콘을 눌러 CHZZK 방송 URL 또는 채널 UID를 입력합니다. 다시보기 URL도 사용할 수 있습니다.
2. **목록 추가 → 멀티뷰 열기**를 선택합니다.
3. 타일을 드래그해 순서를 바꾸고 **메인으로 변경**으로 중심 방송을 선택합니다.

즐겨찾기는 별표로 등록하며 **그룹 관리**에서 편집합니다. 팔로잉은 ↻ 버튼으로 직접 갱신합니다. 방송 목록과 설정은 저장되며, 멀티뷰 페이지를 새로고침해도 복원됩니다.

### 단축키

| 키 | 동작 |
| --- | --- |
| **S** | 스크린샷 미리보기 열기 |
| **R** | 녹화 시작·종료 |
| **F** | 즐겨찾기 열기·닫기 |
| **H** | 화면 잠금·해제 |
| **B** | 상단바 접기·펴기 |
| **V** | 소리 조절 패널 열기·닫기 |
| **G** | 그리드·레이드 뷰 전환 |
| **C** | 채팅 열기·닫기 |
| **← / →** | 3초 뒤로·앞으로 이동 |

멀티뷰 화면에서는 메인 방송, 플레이어 안에서는 해당 방송에 적용됩니다. 채팅·검색 입력 중에는 동작하지 않습니다. 재생바는 타일에 마우스를 올리면 표시됩니다.

상단 오른쪽 **설정 → 일반 단축키 사용**에서 F/H/B/V/G/C와 방향키를 켜거나 끌 수 있습니다. 설정은 저장되며 S/R은 이 설정과 무관하게 사용할 수 있습니다.

### 캡처·녹화 안내

- 스크린샷은 초록색 선택 박스로 영역을 조절하고 **선택 영역 복사/저장**을 누릅니다.
- 녹화 종료 후 결과 창에서 형식과 시작·종료 시간을 선택합니다. 미지원 형식은 비활성화됩니다.
- 녹화는 방송당 **256MB**에서 자동 중지됩니다. 구간 저장·형식 변환은 선택한 영상 길이만큼 시간이 걸립니다.
- 진행 중인 녹화는 페이지를 닫거나 새로고침하면 사라질 수 있습니다. 결과 창을 닫으면 저장하지 않은 임시 영상도 삭제됩니다.

## 업데이트

**기존 설치 폴더**의 파일을 교체하고 확장 관리 페이지에서 **다시 로드**한 뒤 멀티뷰를 새로 여세요. 같은 폴더를 사용해야 기존 즐겨찾기를 유지할 수 있습니다.
