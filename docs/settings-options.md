# 설정 옵션 검토

v2.0.3의 전체 설정은 멀티뷰 단축키와 채팅 모아보기 ON/OFF를 제공합니다. 모아보기 헤더 오른쪽 또는 전체 설정의 모아보기 토글 왼쪽 톱니 아이콘에서 스트리머·관리자·파트너 포함, 닉네임 추가·제외, 수집 내용 초기화와 점검 정보 복사를 관리합니다. 스크린샷 S·녹화 R은 설정과 무관하게 사용하며 입력 중에는 실행하지 않습니다. V는 음소거 대신 기존 소리 조절 패널을 여닫습니다.

| 후보 | 사용자에게 도움이 되는 점 | 검토할 사항 |
| --- | --- | --- |
| 즐겨찾기 자동 갱신 주기 | 인터넷 환경과 갱신 빈도에 맞춰 조절 | 현재 30초 기본값 유지, 요청 중복 방지와 종료 상태 반영 지연 |
| 녹화 기본 형식 | MP4/WebM 선호를 저장 | 미지원 코덱은 사용 가능한 형식으로 대체, 결과 창의 형식 선택과 구분 |

기존 화면에 음량·메인만 듣기·채팅 위치·배치·화면 잠금 버튼이 있으므로 같은 설정을 메뉴에 중복해서 추가하지 않습니다. 후보 옵션은 이번 버전에 구현하지 않으며 이후 사용 수요에 따라 우선순위를 정합니다.

녹화 품질은 저부하(기본: 최대 720p·30fps)와 원본 해상도·프레임 중 선택하며 다음 녹화부터 적용합니다. 저부하 모드는 동영상 디코딩 자체를 줄이지 않고 녹화용 인코딩 해상도·프레임을 제한합니다.

스크린샷 저장은 해당 이미지를 목록에서 제거하고 마지막 이미지 저장 시 자동으로 창을 닫습니다. 복사는 목록을 유지합니다. 별도의 자동 닫기 옵션은 제공하지 않습니다.

제외 닉네임은 추가 입력란 아래에서 관리합니다. 최대 50명이며 전체 닉네임으로 일치합니다. 제외는 자동 역할 수집과 수동 추가에 우선하고 모아보기에만 적용됩니다. × 버튼으로 제외를 해제합니다.
