# 리팩토링 4단계 — viewer 기능 조립 분리

3단계 사용자 테스트 완료 커밋 `16506ae`를 기준으로 진행합니다. 버전은 2.0.3이며 main 반영은 별도입니다.

## 구성

`viewer.js`는 공통 상태·모듈 연결·시작/종료 흐름을 담당합니다. 화면 기능을 구현하는 약 960줄의 코드를 분리해 166줄로 정리했습니다. 코드 줄 수 감소는 성능 개선 수치가 아닙니다.

| 파일 | 책임 |
| --- | --- |
| controllers/view.js | Shadow DOM 생성, 스타일 연결, 홈페이지 모드 진입 |
| controllers/controls.js | 버튼·패널·레이아웃 입력 연결과 초기 표시 |
| controllers/messages.js | 실제 iframe·origin 검증 후 기존 메시지 라우팅 |
| controllers/shell.js | 상단바·잠금·채팅 위치/열림·안내 표시 |
| controllers/favorites.js | 즐겨찾기 상태·온라인 조회·그룹/팔로잉 연결·저장소 구독·갱신 타이머 |
| controllers/channel-list.js | 방송 목록 표시·즐겨찾기/삭제 버튼 |
| controllers/volume-panel.js | 전체/개별 음량 표시, 드래그 상태, 슬라이더 DOM 재사용 |
| controllers/channels.js | 방송 추가/삭제/전체 삭제·이름 조회·목록 교체 조정 |
| controllers/session.ts | 등록 탭 ID·초기화 상태·저장 debounce·스냅샷/목록 요청 |
| models/channel-input.ts | 요청된 방송만으로 목록 구성, 중복 제거와 기존 음량/이름 유지 |

세션 제어와 방송 입력 모델은 strict TypeScript입니다. DOM 컨트롤러는 JS로 동작을 유지하며, ES import는 빌드 시 기존 viewer.js 실행 파일 안으로 묶습니다. manifest의 스크립트 경로와 권한을 바꾸지 않습니다. 레이아웃·플레이어·음량 모델·싱크·미디어·채팅 렌더러는 기존 모듈을 연결합니다.

## 유지하는 규칙

- 살아남은 방송 iframe을 재생성하거나 재배치하지 않습니다. 목록 교체 시 공통 UID의 타일을 유지합니다.
- 음량 UI는 기존 오디오 모델을 호출합니다. 타일 추가·삭제가 다른 방송의 음량·음소거를 바꾸지 않도록 기존 모델을 유지합니다.
- 슬라이더를 드래그하는 동안 해당 입력 DOM과 값을 보존하고 변경된 표시만 갱신합니다.
- 최신 창 저장 권한은 기존 서비스 워커가 판정합니다. 세션 모듈은 VIEWER_SAVE_STATE를 보내며 저장소를 직접 덮어쓰지 않습니다.
- 새로 복원하는 타일의 10%·음소거, 최신 창 기억, 설정 복원 후 이전 창 저장 보류 규칙을 유지합니다.
- 즐겨찾기 새로고침 중 추가/그룹 변경을 잃지 않도록 기존 writeInfo 경로를 유지합니다. 확장 컨텍스트가 만료되면 화면 조회와 저장 가능 여부를 구분합니다.
- 녹화 중 방송 삭제/목록 교체 제한, 캡처·녹화 처리, 단축키·채팅 수집·저장 키는 유지합니다.

## 검증

새 단위 검사에서는 저장 debounce, 최신 상태 스냅샷, 등록 탭·확장 ID 확인, 종료 후 저장 차단을 확인합니다. 입력 모델은 요청 목록 대체·중복 제거·기존 음량/이름·라이브/다시보기 주소를 확인합니다.

기존 브라우저 검사는 초기화·단축키·음량 격리·슬라이더·즐겨찾기/그룹 동기화·갱신 중 수정·타일 재사용·새로고침 복원·채팅·캡처/녹화를 확인합니다. 초기화 실패 시 테스트가 오류 내용을 함께 출력하도록 개선했습니다.

명령: `npm run typecheck`, `npm test`, `npm run test:browser`.

모의 Chrome API/CHZZK 응답으로 수행한 자동 검사입니다. 실제 로그인·실방송·다른 확장과의 동작은 사용자 Chrome에서 확인해야 합니다. 이번 단계는 구조 정리이며 전체 메모리 감소량을 측정하거나 보장하지 않습니다.

## 직접 테스트

1. 새 탭·새 창·치지직 페이지 모드 시작과 이전 방송 목록 복원.
2. 타일 추가·삭제·메인 변경·그리드/레이드 전환 후 남은 방송 재생과 음량 유지.
3. 전체/개별 슬라이더 드래그·음소거·메인만 듣기.
4. 즐겨찾기 추가·그룹 편집·갱신·팝업과의 동기화.
5. 여러 창을 열고 이전 창을 조작/종료해도 최신 창 상태로 복원되는지 확인.
6. 채팅·상단바·잠금·단축키·캡처·녹화와 백업 화면 진입.

다음 5단계에서는 미디어의 Blob·URL·Worker 수명과 피크 메모리를 다룹니다. 전체 JS 전환과 남은 전역 브리지 제거는 후속 단계입니다.
