# 영상 도구 후속 계획

2026-10-13 기준 계획입니다. 현재 배포 코드에는 아래 기능이 구현되지 않았습니다. 구현 순서는 방향키 탐색 → 스크린샷 → 녹화 → 구간 저장으로 제안합니다.

## 방향키 탐색

- 선택한 방송에서 ArrowLeft는 3초 뒤로, ArrowRight는 3초 앞으로 이동합니다.
- 전용 페이지와 플레이어 프레임 양쪽의 키 입력 경로를 처리합니다. 한 번의 입력이 중복 실행되지 않도록 요청 ID와 대상 UID를 연결합니다.
- 채팅·검색 입력, 편집 가능한 요소, 그룹 관리 모달에서는 실행하지 않습니다.
- 기존 프레임 메시지 검증을 유지하고 프레임 내부에서 video.currentTime을 변경합니다. seekable 구간을 확인하고 범위 안으로 제한하며, 버퍼가 없거나 탐색이 불가능하면 안내합니다. 앞쪽 구간과 뒤쪽 구간 사이의 빈 영역도 피합니다.
- 라이브의 앞으로 이동은 현재 재생 가능한 끝까지만 가능합니다. 기존 싱크 수동 조정 상태와 실제 이동량을 함께 갱신합니다.
- 재생 바/슬라이더는 후속 단계로 보류합니다.

## 스크린샷

- 타일 버튼에서 해당 UID의 프레임에 캡처를 요청합니다. iframe 영상에 접근할 수 있는 콘텐츠 스크립트에서 video의 원본 크기로 canvas에 그립니다.
- 전용 페이지에서 미리보기 팝업을 열고 저장·취소를 제공합니다. 미리보기가 열려 있어도 재생을 유지합니다.
- 파일명은 `스트리머명_제목_YYYYMMDDhhmmss.png`입니다. 촬영 시점의 로컬 시각과 UID에 대응하는 신뢰할 수 있는 채널/방송 API 정보를 사용합니다. 현재 코드의 title은 방송인명과 같을 수 있으므로 실제 방송 제목 필드를 별도로 확보합니다.
- 파일명에 사용할 수 없는 문자와 과도한 길이를 정리합니다. 저장 전 캡처 완료 여부를 확인하고 취소·닫기 시 Blob URL을 정리합니다.
- 보호된 영상이나 CORS로 캔버스 추출이 차단되면 실패를 안내합니다. 실제 CHZZK 프레임에서 캡처 가능 여부를 먼저 확인합니다.

## 녹화 및 구간 저장

- 프레임 내부 video.captureStream()과 MediaRecorder로 영상·음성 트랙을 캡처합니다. 지원 MIME 타입을 런타임 조회해 MP4/WebM 선택지를 제공합니다. MP4 미지원 환경에서는 WebM을 제공하고 파일 확장자만 바꾸지 않습니다.
- 녹화 중 표시·경과 시간·중지 버튼을 타일에 제공합니다. 녹화 중 타일 삭제/새로고침은 결과 유실을 막도록 중지·저장 흐름과 연결합니다.
- 중지 후 결과 화면에서 재생 미리보기와 전체 저장/구간 저장을 제공합니다. 구간은 시작·종료 시각으로 선택하고 유효 범위를 검사합니다.
- 원본 녹화는 IndexedDB 등에 청크 단위로 저장하고 결과 페이지에서 읽습니다. 큰 Blob을 runtime 메시지나 chrome.storage.local에 넣지 않습니다. 서비스 워커를 장시간 녹화 프로세스로 사용하지 않습니다.
- 구간 저장은 로컬 Worker의 FFmpeg WASM 도입을 별도 검토합니다. 복사 방식의 키프레임 오차와 정확한 자르기를 위한 재인코딩 비용을 구분합니다. MP4 변환은 컨테이너뿐 아니라 코덱 호환성도 확인합니다.
- WASM·Worker는 확장에 포함하고 MV3 CSP, 패키지 크기, 메모리 사용량, 긴 녹화의 복원·정리 정책을 검증합니다. 처리 중 진행률·취소와 원본 저장을 제공합니다.

## 참고한 구현

[Cheese-PIP](https://github.com/khk4912/Cheese-PIP), 확인 커밋 `0e82a31ecb2ff408105581da3d1f284371049de3`:

- `src/components/screenshot/ScreenshotButton.tsx`: video → canvas 이미지 추출과 미리보기
- `src/utils/record.ts`: captureStream, MediaRecorder, MP4 지원 확인
- `src/entrypoints/record_result/components/TrimModal.tsx`, `src/utils/transcode.ts`: 구간 선택과 FFmpeg 처리
- `src/utils/seek.ts`, `src/components/seek/Seek.tsx`: 버퍼 범위와 방향키 탐색

해당 프로젝트의 package.json은 UNLICENSED로 표시되어 있어 구현 코드를 복사하지 않았습니다. 브라우저 API와 처리 구조를 참고해 이 프로젝트의 메시지·프레임·저장 구조에 맞춰 작성할 계획입니다.

## 검증 기준

실제 Chrome에서 라이브/다시보기, 채팅 입력 중 방향키, 버퍼 경계, 스크린샷 저장/취소 및 파일명, 영상·음성 동기화, MP4 지원/미지원, 긴 녹화, 타일 삭제·새로고침, 구간 저장 시간 오차를 확인합니다.
