# 영상 도구 구현과 후속 과제

2026-10-13 기준 v2.0.0 정식 버전의 구현입니다.

## 현재 동작

- 확장 페이지의 직접 자식 CHZZK 프레임에서만 콘텐츠 스크립트를 활성화합니다. 메시지의 origin, 실제 iframe 창, UID를 확인합니다. 일반 CHZZK 페이지의 하위 프레임에는 플레이어 수정·상태 보고를 적용하지 않습니다.
- `src/content/media-frame.js`는 실제 video 요소의 PNG 캡처, captureStream/MediaRecorder 녹화, 재생 위치 보고 및 이동을 처리합니다. 큰 Blob은 postMessage의 구조화 복제로 전용 페이지에 전달합니다.
- `src/viewer/media-tools.js`는 타일 아이콘·얇은 재생 슬라이더와 S/R 단축키, 스크린샷 저장/취소를 처리합니다. 스크린샷은 이동 가능한 비모달 갤러리에서 여러 장을 선택하며 자르기는 기본 OFF입니다. 저장 후 목록을 유지하고, 녹화는 즉시 시작/토글 종료합니다.
- PNG 파일명은 신뢰할 수 있는 채널명·방송 API 제목과 촬영 시점 로컬 날짜를 사용합니다. 녹화 이름은 `[YY.MM.DD]이름_방송제목`, 구간 저장은 `_X-Ys`를 사용합니다. 파일명 금지 문자를 정리하고 이름·제목의 길이를 제한합니다. 제목 조회 실패 시 `방송`을 사용합니다.
- 종료된 녹화는 IndexedDB에 보관하고 `recording.html`의 별도 결과 창에서 형식·구간을 선택합니다. 원본 형식의 전체 저장은 Blob을 그대로 저장합니다. 같은 형식의 구간 저장은 로컬 모듈 Worker와 Mediabunny 1.63.0으로 압축 패킷을 복사하며 재생·재녹화를 하지 않습니다. 다른 형식은 코덱에 따라 Worker에서 변환하고 지원되지 않는 트랙을 조용히 누락하지 않고 오류로 안내합니다. 결과 창 새로고침에도 복원되며 결과 창을 닫을 때 백그라운드의 탭 종료 이벤트로 임시 결과를 삭제합니다. 창 새로고침에서는 유지합니다.
- MP4/WebM은 MediaRecorder.isTypeSupported로 지원 여부를 확인합니다. MP4 미지원 브라우저에는 WebM을 제공합니다. 확장자만 바꾸는 변환은 하지 않습니다.
- 녹화 데이터는 메모리 청크로 유지하고 방송당 256MB에 도달하면 중지합니다. 원본 영상 트랙을 stop하지 않아 다른 플레이어를 중단시키지 않습니다.
- 구간 복사는 키프레임·패킷 경계에 맞춰 expand하므로 요청 구간 앞뒤가 포함될 수 있으며 프레임 단위의 정밀 자르기를 보장하지 않습니다. 파일명에는 요청한 X-Y를 기록합니다. 진행률과 Worker 종료를 통한 취소를 제공합니다.
- ←/→ 키는 ±3초 이동합니다. 페이지에서는 메인 방송, 플레이어 내부에서는 해당 방송을 대상으로 하며 입력창·모달에서는 적용하지 않습니다. 버퍼/seekable 구간의 경계와 빈 구간을 피하고 기존 싱크 조정 상태에 실제 이동량을 반영합니다.
- 타일 새로고침 버튼은 제거했습니다. 녹화 중 방송 삭제·전체 삭제·팝업 목록 교체를 막고 진행 중인 녹화가 있을 때 페이지 종료 시 경고합니다. 진행 중인 녹화를 강제로 종료하면 데이터는 유실됩니다.

## 참고 자료

[Cheese-PIP](https://github.com/khk4912/Cheese-PIP), 확인 커밋 `0e82a31ecb2ff408105581da3d1f284371049de3`의 ScreenshotButton, record, seek, TrimModal/transcode 구조를 참고했습니다. package.json은 UNLICENSED로 표시되어 있어 소스 코드를 복사하지 않았습니다. 표준 브라우저 API를 사용해 별도로 구현했습니다.

## 후속 과제

- 진행 중인 긴 녹화를 위한 IndexedDB 청크 저장·복구와 전체 메모리 한도
- 장시간 녹화·변환의 CPU/GPU·메모리 프로파일과 실제 코덱별 호환성 추가 검증
- 실제 CHZZK의 영상·음성 트랙 캡처, CORS/보호 영상 제한, 코덱 지원, 긴 녹화와 라이브 탐색 범위 검증

현재 Chrome API와 CHZZK 응답을 모의한 브라우저 테스트를 사용합니다. 생성한 실제 영상 스트림으로 PNG, WebM 녹화와 구간 저장을 확인하되 실제 CHZZK 방송의 녹화 성공을 대신하지 않습니다.

녹화 품질은 chzzkRecordingProfileV1에 저장합니다. balanced(기본)는 원본 재생과 별도의 최대 1280×720 캔버스를 최대 30fps로 그려 약 2.5Mbps로 인코딩합니다. 원본보다 확대하지 않으며 영상 비율을 유지합니다. requestVideoFrameCallback을 우선하고 미지원 시 requestAnimationFrame을 사용합니다. 원본 오디오 트랙을 공유하되 stop하지 않으며 종료 시 자체 캔버스 트랙과 그리기 콜백만 정리합니다. original은 기존 video.captureStream 경로를 유지합니다. 저부하 모드도 인코딩·캔버스 그리기를 사용하므로 무부하는 아니며 원본 재생 자체의 끊김은 복구하지 못합니다. 창 최소화·백그라운드 제한은 실제 Chrome에서 확인해야 합니다.

Mediabunny 배포 파일과 MPL-2.0 라이선스·정확한 원본 소스 위치는 src/vendor/mediabunny에 포함합니다. 외부 CDN, FFmpeg, WASM 다운로드는 사용하지 않습니다. Worker는 결과 창에서만 로드합니다.
