# 즐겨찾기 백업·복원

즐겨찾기는 Chrome 프로필과 확장 프로그램 ID별로 저장됩니다. 압축 해제된 확장을 기존 폴더 대신 다른 경로(dist 등)로 새로 등록하면 다른 ID로 등록되어 기존 데이터가 안 보일 수 있습니다. 저장 키는 리팩토링 전후 동일합니다. 확장 관리에서 이전 확장을 삭제하지 마세요.

## 기존 확장이 남아 있는 경우

1. `chrome://extensions`에서 **이전 확장**의 ID를 확인합니다.
2. 이전 확장의 **서비스 워커 → 검사**를 열고 Console에서 아래 코드를 실행합니다. 이전 확장을 다시 로드하거나 삭제할 필요는 없습니다.

```js
copy(JSON.stringify(await chrome.storage.local.get([
  'chzzkMultiviewFavoritesV08',
  'chzzkMultiviewFavoritesV07',
  'chzzkMultiviewFavoriteGroupsV02',
  'chzzkMultiviewFavoriteGroupsV01',
  'chzzkFavoriteGroupOptionsV2'
]), null, 2))
```

3. 클립보드 내용을 메모장에 붙여넣고 **UTF-8**로 `favorites-backup.json`에 저장합니다. JSON에서 즐겨찾기 항목이 들어 있는지 확인하세요.
4. 새 확장의 **그룹 관리 → 백업 불러오기**에서 파일을 선택합니다.
5. 항목 수를 확인하고 기본값인 **기존 목록에 합치기**로 불러옵니다. 기존 이름·순서를 유지하면서 없는 방송과 그룹 소속을 추가합니다. 전체를 백업과 동일하게 만들려면 **백업으로 교체**를 선택합니다.

서비스 워커 검사가 열리지 않으면 이전 확장의 ID로 `chrome-extension://이전ID/src/popup/popup.html`을 새 탭에 열고 F12 Console에서 같은 코드를 실행할 수 있습니다. 이때도 **이전 ID** 페이지에서 실행해야 합니다.

기존 확장을 이미 삭제했고 외부 백업도 없다면 새 확장만으로 이전 저장소를 읽어 복구할 수는 없습니다.

## 다음 업데이트부터

- **그룹 관리 → 즐겨찾기 백업**을 누르면 백업 탭이 열립니다. **프로젝트 폴더 선택** 후 **즐겨찾기 백업**을 누르면 프로젝트 안의 `.backup`에 JSON을 저장합니다. 팝업·두 멀티뷰 실행 모드에서 사용할 수 있습니다.
- 즐겨찾기 이름·그룹 소속·순서·빈 그룹·그룹 강조색을 보관합니다. 로그인 정보·쿠키·채팅·녹화는 포함하지 않습니다.
- 파일 선택만으로 저장하지 않습니다. 미리보기 후 **불러오기**를 눌러야 반영됩니다. 잘못된 형식은 저장하지 않습니다.
- 불러오기 직전 목록을 같은 확장의 저장소에 한 개 자동 보관합니다. **불러오기 전 목록 복구**에서 미리보기 후 적용할 수 있습니다. 이 자동 보관도 확장을 삭제하면 사라질 수 있으므로 외부 JSON 백업을 보관하세요.
- 이후에는 같은 설치 경로를 유지하고 빌드 후 **다시 로드**합니다. 설치 경로를 바꿔야 한다면 먼저 백업하고 새 확장으로 불러오세요.
