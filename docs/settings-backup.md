# 설정 내보내기·불러오기

팝업 또는 멀티뷰 상단 **설정 → 설정 내보내기 / 불러오기**를 누르면 백업 탭을 엽니다.

## 내보내기

**설정 내보내기**를 누르고 `CZ-settings-YYYY-MM-DD.json`을 저장합니다. 열려 있는 가장 최근 멀티뷰의 상태를 먼저 조회하며, 해당 화면이 응답하지 않으면 마지막 저장 상태를 사용합니다.

포함 항목:

- 즐겨찾기 이름·그룹 소속·순서, 빈 그룹, 강조색
- 마지막 방송 목록·메인 선택, 배치, 전체 음량·메인만 듣기, 채팅 열림·좌우 위치, 화면 잠금, 멀티뷰 단축키
- 주요 채팅 사용·역할 필터·추가/제외 사용자·영역 높이
- 녹화 품질

로그인 쿠키·계정 인증 정보, 팔로잉 조회 캐시, 수집한 채팅, 스크린샷·녹화 파일, 실행 중인 탭 ID는 포함하지 않습니다.

## 불러오기

1. **설정 불러오기**로 파일을 선택합니다. 선택만으로 저장하지 않습니다.
2. 미리보기에서 즐겨찾기·그룹 수를 확인합니다. 전체 설정 백업은 현재 설정과 즐겨찾기를 **교체**합니다.
3. **불러오기**를 누릅니다.
4. 열려 있던 멀티뷰를 새로고침합니다. 새로고침 전 기존 화면의 세션 저장은 보류하여 복원한 설정을 덮어쓰지 않도록 합니다. 녹화 중이라면 저장을 마친 후 새로고침하세요.

방송 복원 시 타일이 10%·음소거로 시작하는 기존 규칙은 유지합니다. 녹화 품질과 멀티뷰 설정은 새로고침한 화면에 반영됩니다.

잘못된 형식·지원하지 않는 버전은 적용하지 않습니다. 불러오기 직전 설정을 저장소에 한 개 자동 보관합니다. **불러오기 전 설정 복구**에서 미리보기 후 되돌릴 수 있습니다. 이는 같은 확장 내부의 복구용 복사본이므로 확장 삭제에 대비하려면 외부 JSON 파일을 보관해야 합니다.

## 기존 즐겨찾기 백업과의 차이

이전의 `favorites-backup.json` 또는 `CZ-favorites-...json`은 **그룹 관리 → 백업 불러오기**에서 사용합니다. 즐겨찾기만 합치거나 교체하며 다른 설정은 건드리지 않습니다. [기존 데이터 이전 안내](favorites-backup.md)를 참고하세요.

## 복구용 manifest를 수정했던 경우

즐겨찾기 JSON을 먼저 별도로 저장해 두고, 저장소에서 임시로 바꾼 `manifest.json`을 원래 코드로 되돌린 뒤 빌드하세요.

```sh
git restore manifest.json
git pull --ff-only
npm run build
```

기존에 등록한 **동일한 dist 경로**의 확장을 다시 로드합니다. 다른 폴더를 새 확장으로 등록할 때는 백업 JSON으로 이전하세요.
