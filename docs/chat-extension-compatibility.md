# 채팅 수집 확장 호환성 검토

검토 대상:

- [배지 모아 챗](https://chromewebstore.google.com/detail/elfbgpccophooginnjagaginhhddpdlh)
- [Badge Collector](https://chromewebstore.google.com/detail/gbcdobpipglclbhabpkacoecddmopojp)

이 환경에서 Chrome 웹스토어와 공개 확장 배포 서버가 403으로 차단되어 두 확장의 소스·manifest는 확인하지 못했습니다. 실제 설치·수집 테스트도 수행하지 않았습니다.

## 현재 제공하는 사용 경로

멀티뷰 채팅 영역의 **원본 방송 열기**로 현재 메인 방송을 일반 CHZZK 탭에서 엽니다. 새 탭은 중복 소리를 막기 위해 음소거하며 페이지 DOM은 수정하지 않습니다. 기존 채팅 수집 확장은 해당 원본 탭에서 사용합니다. 일반 CHZZK 페이지에서 두 확장이 정상 동작하는지 사용자 확인이 필요합니다.

## 멀티뷰 내부 직접 호환

멀티뷰는 확장 페이지이고 방송·채팅은 그 안의 CHZZK iframe입니다. 타사 확장이 최상위 CHZZK 탭에서만 실행하거나 특정 DOM·플레이어·채팅 연결을 요구하면 멀티뷰 안에서 동작하지 않을 수 있습니다. 우리 확장에서 타사 확장의 host 권한, 프레임 실행 설정 또는 소스를 변경하거나 강제 실행할 수는 없습니다.

직접 통합하려면 두 확장의 소스 또는 제작자 문서를 통해 iframe 지원, URL 매칭, 메시지 수집 방식, 연동 API 유무를 확인해야 합니다. 수집 내용을 멀티뷰에 표시하려면 상대 확장이 제공하는 명시적인 연동 인터페이스도 필요합니다. 현재 원본 탭 열기는 내부 통합을 구현했다는 의미가 아닙니다.
